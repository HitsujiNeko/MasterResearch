# 採用観測の気温と LST の対比（観測条件の記述）

**最終更新**: 2026-10-30  
**関連ドキュメント**: [observation_selection.md](../02_methods/observation_selection.md) 5章・8.4節, [gee_calc_LST.md](../02_methods/gee_calc_LST.md)  
**前提知識**: 気温（地上約2mの空気の温度）と LST（地表面の放射温度）が別の物理量であること、採用観測の区分（主採用・比較用）  
**対象RQ**: なし（論文の対象地域・データの節で、観測条件を記述するために用いる）

---

## 0. 要旨

採用観測3件（主採用 `2022-09-06T03:23:58`、比較用 `2023-07-07T03:23:05`・`2024-11-30T03:23:36`、いずれも UTC・現地時刻 10:23）について、
衛星通過時刻の気温を2つの出典から取得し、LST と並べた。

- 気温は、雨季の2件で 31.6〜34.0°C、乾季の `2024-11-30` で 21.7〜23.0°C だった（観測所・ERA5-Land とも）
- LST は、どの地点・観測でも気温より高かった。観測所付近（3×3 画素）では観測所の気温より +3.8〜+6.7°C、
  ROI 平均では ERA5-Land の ROI 平均より +0.5〜+3.0°C 高い
- 観測所の気温と、その地点の ERA5-Land の値の差は 1.0°C 以内だった。ただしハドンの気温は通過の約24分前の値、
  ノイバイの気温は整数°C の報告であり、この差はそれらによるずれを含む（1.3節）

**この表は観測条件の記述であり、LST の妥当性検証ではない。** 気温と LST は別の物理量であり、
気温は LST の正解値にならない。3件のみのため、気温と LST の回帰式は作らない。

単位は °C（有効画素数を除く）。LST の統計量は ROI 内の有効画素（画素中心が ROI 内・NaN でない画素）で求め、標準偏差は母標準偏差である。
LST は雲マスク後の有効画素だけの統計量（ROI の約89〜94%）であるのに対し、ERA5-Land は ROI 全体の平均であり、比べている範囲は一致しない。
LST の標準偏差は [observation_selection.md](../02_methods/observation_selection.md) 8.3節の表（GEE 側の集計）と小数第2位で異なる（`2023-07-07` は 2.55 に対し 2.54、`2024-11-30` は 2.04 に対し 2.03）。集計に使った画素の集合の違い（GEE 上の 30m の集計か、GeoTIFF の画素か）によると考えられる（**推定**。`2023-07-07` の有効画素率は同章の 88.7% に対し GeoTIFF では 89.4% で、画素の集合が一致していない）。

### 1.3 表の注

- **観測時刻**: 観測所の気温は、通過時刻に最も近い観測の値である。ノイバイは30分ごとの METAR（`FM-15`）で、
  気温は整数°C で報告される（丸めによる不確かさ ±0.5°C）。ハドンは3時間ごとの SYNOP（`FM-12`）で、通過時刻に最も近い 03:00 UTC の値
  （約24分前）を使った。通過時刻への内挿はしていない。通過時刻との差が ±90分を超える観測しか無い場合は欠測とする
- **ハドンの時刻のずれの向き**: 観測は午前の昇温期にあたり、ハドンの 03:00〜06:00 UTC の昇温率は 0.9〜1.2°C/時、
  同じ地点の ERA5-Land の 03:00〜04:00 UTC の昇温率は 1.1〜1.3°C/時だった。このため 03:00 の値は通過時刻の気温より
  0.4〜0.5°C 程度低く、ハドンの「LST − 観測所の気温」は同程度大きめに出ていると考えられる（**推定**。00:00〜03:00 UTC の
  昇温はさらに速く、この幅は下限寄りの可能性がある）。同じ 03:00 UTC どうしで比べると、ハドンの気温と同じ地点の ERA5-Land の
  差は −0.02〜+0.15°C にとどまり、表のハドンの行で ERA5-Land（通過時刻へ内挿）より 0.3〜0.5°C 低いのは、主にこの時刻のずれによる
- **ERA5-Land**: 再解析値であり、都市内の気温差は表せない。モデル本来の格子は約9km で、GEE では 0.1度（緯度方向で約11km）の
  格子に置き直されている（集計の scale はこの 0.1度に当たる 11,132m）。通過時刻をはさむ2つの正時
  （03:00・04:00 UTC）の値を線形内挿した。観測所の行は観測所の座標を含む格子の値、ROI の行は ROI の平均である
- **観測所付近の LST**: isd-history.csv の座標（ノイバイ 21.221, 105.807・ハドン 20.967, 105.767）を含む画素を中心とする
  3×3 画素（約 90m 四方）の平均である。ISD の毎時値の CSV に記録された座標と比べると、ノイバイ（21.221192, 105.807178）とは
  約30m の差で窓の中に収まるが、ハドン（20.9666666, 105.7666666）は1分単位に丸められた座標であり、測器の位置の不確かさは
  約 ±900m ある。このため、特にハドンの 3×3 の LST は、測器の周囲の地表面を表しているとは限らない。
  ノイバイは空港の敷地内にあり、滑走路や駐機場などの舗装面を含む可能性がある（**推定**。現地・画像では確かめていない）
- **妥当性検証ではない**: LST − 気温の値は、地表面と空気の温度差を含む観測条件の記述である。LST の誤差を示すものではない

## 3. 取得・算出の手順

| 段階 | 内容 | スクリプト |
|---|---|---|
| ISD の取得 | NCEI Access Data Service（`dataset=global-hourly`）から、2観測所 × 3観測日の 00:00〜06:59 UTC を取得し、`data/input/air_temperature/isd/{観測所番号}_{YYYYMMDD}.csv` に保存 | [fetch_isd_hourly_hanoi.py](../../src/preprocessing/fetch_isd_hourly_hanoi.py) |
| ISD の気温 | `TMP` 列（10倍した摂氏の整数,品質コード）を °C に換算。欠測（`+9999`）と品質コード 2・3・6・7（疑わしい・誤り）を除き、通過時刻に最も近い観測を採る（時刻差が同じなら通過前。時刻差が ±90分を超える場合は欠測） | [compare_air_temperature_lst.py](../../src/analysis/compare_air_temperature_lst.py) |
| ERA5-Land | GEE の `ECMWF/ERA5_LAND/HOURLY` の `temperature_2m`（K）を、GEE の格子（0.1度・11,132m）で ROI 平均（`reduceRegion`・平均）と観測所の点（`reduceRegion`・`first`）について読み、通過時刻へ線形内挿して °C に換算。`getInfo()` で値を読むだけで、エクスポートはしていない | 同上 |
| LST | 採用観測の LST GeoTIFF（[observation_selection.md](../02_methods/observation_selection.md) 5章）から、観測所付近の 3×3 画素と ROI 内の有効画素の統計量を算出 | 同上 |

再現のコマンド（ISD の CSV は追跡下にあり、取得し直す必要はない）:

```bash
python -m src.preprocessing.fetch_isd_hourly_hanoi
python -m src.analysis.compare_air_temperature_lst
```

- 出力は `data/output/air_temperature/` の対比表 CSV とサマリー JSON（来歴・パラメータ・ERA5-Land の内挿前の値〔K〕）
- LST GeoTIFF（`data/satellite/lst/`）と ROI（`data/gis/boundaries/`）は git 管理外である。別の場所にある場合は `--lst-root`・`--roi-path` で指定する
- **GEE の注意**: 2024年の ERA5-Land の画像は格子の原点が −360.05度（2022年は −180.05度）で、`sampleRegions`・`reduceRegions` では点の値が返らなかった。
  点ごとの `reduceRegion` では値が返るため、そちらを使っている（2026-10-29 確認）
- ISD の `DATE` 列を UTC として扱っている。ISD の仕様に基づくもので、データから独立には確かめていない

## 5. 限界・未確認事項

- 観測所は2か所で、ノイバイは都心から北へ約20km の空港、ハドンは都心の南西の市街地にある。都心部の気温を直接表す観測所は無い
- ERA5-Land の格子（約9〜11km）では、ROI 内の都市と郊外の気温差を表せない。ROI 平均の LST − ERA5-Land は、地表面と空気の温度差に加えて、この解像度の違いを含む
- 観測所付近の LST の 3×3 画素が、測器の周囲のどの地物に当たるかは確かめていない。ハドンは座標の不確かさ（約 ±900m）が窓より大きい（1.3節）
- 3件のみであり、気温と LST の関係式や季節差の一般化は行わない。必要になれば別タスクで検討する
