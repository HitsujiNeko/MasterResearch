# Issue 起票スキル

会話またはintakeファイルから要件を整理し、Issue作成からプロジェクト設定までを一体実行する。

## 実行手順

以下のチェックリストをコピーして進捗を追跡する:

```text
- [ ] Step 1: 要件整理・Issue本文の下書き・ユーザー承認
- [ ] Step 2: Issue作成 → プロジェクト追加 → ステータス・優先度設定（3ステップ一体）
- [ ] Step 3: 完了報告
```

### Step 1: 要件の整理とユーザー承認

1. `.github/ISSUE_TEMPLATE/task.md` のセクション構成に沿って要件を整理する
2. `.github/task-workflow.md` のラベル一覧・マイルストーン一覧から適切な値を選択する
3. Issue本文・ラベル・マイルストーンの下書きをユーザーに提示する
4. **優先度は推測せず、必ずユーザーに確認する**（intakeファイルに明記されている場合はそのまま採用）

**入力**: intakeファイル（`.github/prompts/active/_intake_{slug}.md`）が開かれていれば入力として使用。なければ会話で要件を整理する。

### Step 2: Issue作成とプロジェクト設定

ユーザー承認後、以下の3ステップを**途中で中断せず一体実行**する。

1. **Issue作成**: 日本語本文はBashツールで一時ファイルに書き出し `--body-file` で渡す
2. **プロジェクト追加**: `gh project item-add 1 --owner HitsujiNeko`
3. **ステータス・優先度設定**: GraphQLで「未着手」と指定優先度を設定。ID一覧は [reference.md](reference.md) を参照

**認証エラー時**: `gh auth refresh -s project` の実行を案内し、設定未完了を明示的に警告する。暗黙にスキップしない。

### Step 3: 完了報告

作成結果（URL・ラベル・マイルストーン・ステータス・優先度）をユーザーに報告する。intakeファイル使用時は削除を案内する。

## 注意事項

- このスキルはIssue起票のみを行う。タスク実行（ブランチ作成・実装）は行わない
- 1 Issue = 1 PRで完結する変更単位が目安。スコープが大きい場合は分割を提案する
