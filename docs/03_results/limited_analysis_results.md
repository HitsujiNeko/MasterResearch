## 1. 位置づけ

RQ3 では Full / Limited / Satellite Only の3シナリオを比較する。Satellite Only は cell_id結合の新経路で既に成立済み（[satellite_only_analysis_results_cellbased.md](satellite_only_analysis_results_cellbased.md)）であり、本ドキュメントは公開GISと衛星指標を組み合わせた **Limited** シナリオの評価結果を記録する。Full シナリオ（測量GISの追加）は本ドキュメントの対象外（未着手）。

**本ドキュメントの全ランは観測 `2023-07-07T03:23:05Z`（以下 032305）に基づく。** 観測 `2023-07-07T03:23:29Z`（032329）に基づく旧ラン1〜13 の記録は [limited_analysis_results_20230707_032329.md](../04_archive/limited_analysis_results_20230707_032329.md) へ移した。**旧記録とはカバレッジ・建物高さの帰属方式・人口/夜間光の nodata 方針が食い違うため、数値を直接比較してはならない**（アーカイブ側 0.1節）。ラン番号も振り直しているため、番号だけで旧記録を参照しないこと（対応表はアーカイブ側 0.2節）。

**シーン選定の根拠**（032305 を採用した理由・2シーン合成を採らなかった判断を含む）は [observation_selection.md](../02_methods/observation_selection.md) を正本とする。

### 1.2 現行の定義（建物高さ・人口・夜間光）

本ドキュメントの全ランは、次の定義で生成したデータセットに基づく。**旧記録との差はここに集約される。**

- **建物高さの帰属方式**: 重なりベースと重心の併用。旧方式（重心単独）では大規模建物の張り出しセルが `BUILD_H_MEAN` / `BUILD_H_MAX` の NULL になり非NULL要求フィルタで系統的に脱落していたが、現行方式では建物高さ由来の脱落が **21セル**にとどまる（3.8節）。ただし `BUILD_H_MEAN` は**混成推定量**（大半のセルは上端高さの面積平均、重なり方式の被覆が無いセルは重心方式の単純平均）であり、fine セル中心を覆わない小さい建物は重み0で落ちるため、この測定誤差はハノイの都市形態（大フットプリント＝低層、小フットプリント＝中高層）に沿って**密集低層地区で下方へ偏る**。詳細は [gis_data_buildings.md](../01_planning/gis_data/gis_data_buildings.md) 3.2節を参照する
- **人口・夜間光の nodata 対処**: 原因ごとに扱いを分ける。**境界帯型**（ROIクリップ×粗い画素。LandScan約920m・VIIRS約460m）は有効域を明示的な品質列（`VALID_POP_<ソース>_MASK` / `VALID_NTL_MASK`）として除外し、補完しない。**WorldPopマスク型のうち水域優位**（`LULC_WATER_COV >= 0.9`）のセルは0で補完し、`POP_FILLED_<ソース>` フラグ列で「補完した実測0」と区別する。**水域と断定できない陸地**（92m画素の無効値マスクが陸地部分まで巻き込んだセル等）は補完せず除外を維持する。原因別の実測は [gis_data_population.md](../01_planning/gis_data/gis_data_population.md) 6.4節・[gis_data_nighttime_lights.md](../01_planning/gis_data/gis_data_nighttime_lights.md) 5.1節、集計方法は `src.analysis.diagnose_nodata_dropout` を正本とする

境界帯型を陸地であるにもかかわらず0補完しない・水域優位以外の WorldPop 欠測セルを補完しないのは、いずれも根拠の無い外挿・誤った0埋めを避けるためである（920m画素の値をROI外向きに延ばす根拠は薄く、水域と判定できない陸地に人口0を与えるのは誤りになる）。この方針の実データ上の帰結は3.8節に記録する。

### 1.3 結果の一般化可能性の限界

本ドキュメントの全ランは **ハノイROI・30m・単一観測（032305）** の結果である。したがって次の点は**検証されていない**。

- **季節・時刻**: 乾季／雨季、他の時刻の観測での再現性。植生指数と土地被覆の関係は季節依存が大きいと予想されるが、本研究では未確認
- **他都市**: ベトナム他都市および他国の都市での再現性
- **他スケール**: 90m・300mでの再現性。特に土地被覆の面積率は30mで二値化しており（5.5.1節）、粗いスケールでは性質が変わる
- **空間カバレッジ**: 母集団はLST有効セル（ROI内 3,736,107セルの89.3%）に依存する。南部の一部（観測フットプリント端）と北東部の雲域を除いてROIをほぼ覆うが（3.8節の目視確認）、**カバレッジが変われば母集団の性格も変わる**
- **母集団の性格**: 都心に加えて農村部と山地を広く含む。土地被覆は農地が支配的であり（`LULC_CROP_COV` の平均 0.6554・5.5.1節）、都市域のみを対象とした研究の知見がそのまま当てはまるとは限らない

「分光指数が被覆率型を上回る」（4.3節。**RF に限定した観察であり、線形モデルでは向きが逆になる**）を含む本ドキュメントの結論は、**上記の条件下での観察**であり、条件を変えた場合の一般性を主張するものではない。

### 2.1 台帳の読み方（比較してよい組み合わせ）

**数値を直接比較してよいかどうかは、母数だけでなく標本まで揃っているかで判断する。** `sample_dataset` は母数に対して位置指定で10万件を抽出するため、**母数が数百セル違うだけで抽出位置が総入れ替えになる**。偶然一致の基準値は 10万 / 3,274,665 ≒ 3.05% であり、重なり率がこの水準にとどまるランどうしは事実上独立な2標本とみなす。

| 比較軸 | 対象ラン | 母数 | 標本の重なり | 標本統制 |
|---|---|---|---|---|
| 変数セット | 1・3・4 | 3,274,665（一致） | 100% | **あり** |
| 建物高さ構成 | 1・5・6・7 | 3,274,665（一致） | 100% | **あり** |
| 人口ソース | 8 対 9 | 3,273,800（一致） | 100% | **あり** |

- **変数セット軸・建物高さ軸は同一セル上の比較である。** 非NULLを要求するフィルタ列を変数セット・建物高さ構成に依らず一定にしている設計による（3.2節・3.3節）。本ドキュメントで最も統制の効いた比較であり、差を実質的な違いとして読んでよい
- **ソース差し替え軸（人口・土地被覆）は統制されていない。** フィルタ列は「選択した人口版のみ」を要求する設計であり（投入しない版の欠測で母数を減らさないことを優先した）、土地被覆は入力データセット自体が別である。**ソース間の差は符号を含めて実質的な違いとして読んではならない**（5.5節・5.6節）
- **同一ソース群の内部（8対9・10対11）は統制されている。** 人口2版の比較・Esri内の変数セット比較は同一セル上で行われている
- **ラン2（gismask）は母数が大きく異なる。** `VALID_GIS_MASK == 1` の限定によるものであり、ラン1との比較はフィルタ条件の効果を見るためのものである（6.6節）

#### 標本変動の実測

ラン間の差を「実質的な違い」と読んでよいかの物差しとして、**標本の入れ替わりだけで各指標がどれだけ動くか**を実測した。母集団（3,274,665セル）とラン構成をラン1に固定し、`--random-state` だけを 42（ラン1）・43・44 と変えて3標本を抽出している。3標本の相互の重なりは 3.01〜3.16% で偶然一致水準（3.05%）と一致し、独立な標本とみなせる。

**本測定は分析ランではなく診断であり、出力は一時ディレクトリへ出して追跡下には置いていない**（台帳にも載せない。3.9節のブロックサイズ診断と同じ扱い）。再現コマンドは次のとおり。

```bash
python -m src.analysis.analysis_rq3_limited --random-state 43 --output-dir <一時ディレクトリ>
```

**読み方**:

- **R² の標本変動は 0.003 程度**である。ラン間の R² 差がこの水準にとどまるなら、実質的な違いとして読まない
- **SHAP の標本変動は大きい**（`NDWI` で 0.1366、`LULC_BUILT_COV` で 0.0842）。SHAP の差を論じるときは 0.1 程度の変動を織り込む。SHAP 上位の順位も第4位までは3標本で安定するが、**第5・6位（`NDVI` と `NDWI`）は入れ替わる**
- **fold間sd 自体が標本で2倍近く動く**（0.0263〜0.0451）。**fold間sd をラン間の差の物差しに使わない**
- VIF は分光指数で相対 0.6%、建物高さで相対 8.1% 変動する。**危険水準（>10）を超えるかの判定には十分だが、数ポイントの差は読まない**
- **この測定は母集団を固定している。** 母集団自体が異なる比較（ソース差し替え軸・フィルタ条件軸）では、ここで測った変動は**下限**にすぎない

## 3. ラン間で共通の処理条件

以下の条件は全ランで共通である。ランによって変わる項目は、2節の台帳へ列として置く。

### 3.1 ROI・スケール・格子・観測

- ROI: ハノイ
- スケール: **30m**
- 格子: 30m正準グリッド（全 **3,739,454行**）。Satellite Only と同一の格子であり、`cell_id` で結合する
- 観測: **`2023-07-07T03:23:05Z`（Landsat 8）で全ラン共通**

### 3.2 建物高さ列の補完

`BUILD_H_MEAN`/`BUILD_H_MAX` は、高さが取れる建物が1つも無いセルでNULLになる。「建物が無い」の判定は `BUILD_COV == 0`（被覆率）単独ではなく、`BUILD_COV == 0 AND BUILD_DEN == 0`（棟数密度も0）で行う。

`BUILD_COV` はfineグリッドへのラスタ化による近似であり、`gis_data_buildings.md`「小さい建物の取りこぼし」の実測によれば、30mでは建物の重心が存在するセル（`BUILD_DEN > 0`）の**14.0%**で `BUILD_COV == 0` になる（GBAの建物の80.7%が100m²未満で、fine 10mセルの中心を1つも含まない場合に被覆率へ寄与しないため）。ただし `BUILD_DEN` も逆方向に取りこぼす（重心が隣セルにあり輪郭だけが張り出した大きい建物）ため、`BUILD_DEN` 単独でも「建物が無い」の判定はできない。

この2条件のANDに基づき、`BUILD_COV == 0 AND BUILD_DEN == 0` のセルのみ「建物が無い ⇒ 建物高さ0m」として0補完し、`BUILD_COV > 0` または `BUILD_DEN > 0` なのに高さNULL（真の欠落）のセルは補完せず、後段の非NULL要求フィルタで除外した。

| 母集団 | 補完セル数 | 比率 |
|---|---|---|
| データセット全体（3,739,454） | 2,781,918 | 74.4% |
| ラン1のフィルタ後母数（3,274,665） | 2,387,100 | 72.90% |
| ラン2のフィルタ後母数（1,309,830） | 422,265 | 32.24% |

**比率は母集団を明示して読む必要がある。** 建物が存在するセルへ限定するラン2で比率が大きく下がるのは定義どおりの挙動である。

**補完はどの建物高さ構成でも同一に行う。** 下記の `--building-height` は「補完後の2列のうち、どれをモデルへ投入するか」だけを切り替えるものであり、補完の判定条件・件数には影響しない。

#### 建物高さ列の構成（`--building-height`）

`BUILD_H_MEAN` と `BUILD_H_MAX` は同一の建物ポリゴンから集計した高さであり強く相関するため（Pearson +0.985・6.2節）、2列とも投入するとVIFが危険水準を大きく超える（6.4節）。投入する高さ列は `--building-height` で切り替える。ラン別の値は2節の台帳「建物高さ」列を正本とする。

| 値 | 投入する列 | 備考 |
|---|---|---|
| `both` | `BUILD_H_MEAN` + `BUILD_H_MAX` | ラン5の構成 |
| `mean` | `BUILD_H_MEAN` | **採用構成（既定）**。セル内の平均建物高さ |
| `max` | `BUILD_H_MAX` | セル内の最高建物高さ |
| `pc1` | `BUILD_H_PC1` | 2列を標準化して合成した第1主成分（合成列） |

全構成に共通する仕様は次のとおり。

- **非NULLを要求するフィルタ列は構成に依らず高さ2列のまま**であり、母数・分析サンプルは構成間で完全に一致する（2.1節）
- **相関行列の対象列は構成に依らず一定**（拡張後の全候補列）であり、`BUILD_H_PC1` は対象に加えない。診断すべきは元の2列の相関そのものであるため（6.2節）
- `pc1` の主成分は**分析サンプル全体で1回fitする**（Spatial CVのfold内ではfitし直さない）。符号は `BUILD_H_MEAN` への寄与が正になる向きへ揃える。loadings・寄与率・標準化統計は `*_results.json` の `building_height_pc1` に記録する。実測値と fold 内 fit を採らなかった根拠は6.4節
- 出力ファイル名の `_bh_{構成}` は **`both` のときだけ付けない**。既定を変えても `both` で実行済みのランの出力名が動かないようにするためである（3.7節）

### 3.3 品質管理（フィルタ条件）

全ランに共通して、以下を満たすセルを残す。

- マスク段（`required_mask_columns`）: `IN_ANALYSIS_AREA == 1`・`VALID_POP_<選択した人口ソース>_MASK == 1`・`VALID_NTL_MASK == 1`
- 指定した説明変数列と `LST` が非NULL（建物高さ補完後）
- `LST_VALID_RATIO >= 0.5`

**人口・夜間光は非NULL要求フィルタではなく有効域品質列で判定する**（1.2節）。このため後段の脱落内訳（3.8節）には人口・夜間光の要因が現れない。品質列による実効的な脱落の規模はそちらで別途示す。

`VALID_GIS_MASK == 1` を追加で課すかどうかはランごとに変わるため、台帳の「フィルタ条件」列で示す。

`VALID_GIS_MASK == 0` は全件 `no_gis_feature`（`build_dataset.py` のコメントにより「分析上は0として扱ってよい」観測結果）であり、`missing_gis_data` は0件だった。**ただしこの「0件」は、建物パラメータテーブルが正準グリッドの全セルに結合できたこと（テーブル結合の完全性）を示すのみであり、GBAが現地の建物を漏れなく検出できていること（データそのものの正確性・有効カバレッジ）までは検証していない**（`BUILD_COV`/`BUILD_DEN` は結合の有効域外でも常に0.0を返す設計のため、結合が成功していれば `missing_gis_data` は構造的にほぼ0件になる。3.2節で述べた小規模建物の取りこぼしはこの「0件」では検出できない）。

この限界を踏まえたうえで、**主結果では `VALID_GIS_MASK` を課さず有効域全体を対象**とする（`VALID_GIS_MASK == 0` のセルを「GIS特徴量が観測結果として0」として扱う判断自体は妥当であり、テーブル結合の完全性は確認済みのため）。判断の妥当性は6.6節で検証する。

### 3.4 サンプリング

- 適用順序: 建物高さ補完 → フィルタ → サンプリング → ブロック割り当て（ブロック割り当てを先にすると各ブロックのセル数が不均等に減り、fold のサイズ均衡が崩れるため）
- サンプル数: `100,000`
- 乱数シード: `42`
- サンプル内の建物高さ補完セル数: ラン1 **72,657件**（72.66%）、ラン2 **32,012件**（32.01%）

  この値は3.2節の「フィルタ後母数における補完セル数」とは異なる母集団（フィルタ後の全件 vs 10万件サンプル）に対する集計であり、両者は一致しない（比率はほぼ一致: ラン1 72.90% vs 72.66%、ラン2 32.24% vs 32.01%）。研究記述で引用する際はどちらの母数か明記すること。

### 3.5 モデル設定

- 学習 / テスト: `80,000 / 20,000`（random split、`test_size=0.2`）
- 目的変数: `LST`（°C）
- MLR: 説明変数・目的変数の両方を標準化（標準化偏回帰係数として解釈）
- RF: `n_estimators=300`, `min_samples_leaf=5`
- Spatial CV:
  - `5-fold`（Group K-Fold、group = 空間ブロックID）
  - ブロックサイズ: `2,700m`
  - 非空ブロック数: 台帳の「ブロック」列（10万件サンプル後ベース）
- SHAP: 評価サンプル `2,000`、background `500`

**Spatial CV の R² の読み方（重要）**: ブロックサイズ 2,700m では LST の空間自己相関を断ち切れていない。本ドキュメントが報告する Spatial CV の R² を**「未知の場所への汎化性能」として読んではならない**（同一ROI内・空間的に近い場所への内挿性能として読む）。実測の根拠は3.9節を参照する。

### 3.6 分散0の特徴量列の除外

説明変数のうち分析サンプル内で分散が0になる列は、VIF算出・モデル学習の前に除外する。定数列を残すと `compute_vif` の補助回帰が決定係数1.0を返し、**VIFが `inf`（完全共線）と報告される**が、これは実体のある共線性ではなく定数列に起因する偽陽性であり、多重共線性の診断そのものを汚染するためである。

GLC を土地被覆ソースとするラン（1・2・4〜9）では `LULC_BARE_COV` が除外された。ハノイROIのGLC_FCS30Dには裸地クラス（200・201・202）の画素が1つも存在せず、**全セルで厳密に0.0になる**（実測100.00%・5.5.1節）ためである。**Esri を用いたラン（10・11）では裸地画素が存在するため除外は発生しない**（Esri の変数数が1つ多い理由）。除外した列名は各ランの `*_results.json` の `dropped_constant_features` に記録している。

判定は母集団ではなく分析サンプル（10万件）に対して行う。VIF も同じサンプルで算出するため判定対象を揃える必要があるが、代償として母集団での出現頻度が低いクラスはサンプル依存で除外されうる。

`filter_dropout.dropped_summary` は `target_available` 以降の脱落しか対象にせず、**品質列（マスク段）で落ちるセルを評価しない**。品質列による脱落は水域寄りに偏るため、LST有効なROI内セルを母集団として水域被覆の階級別に残存率を確認した。

| 水域被覆（`LULC_WATER_COV`） | 母集団 | 最終母数 | 残存率 | うち品質列で除外 |
|---|---|---|---|---|
| なし（0） | 3,063,075 | 3,016,341 | 98.47% | 28,285 |
| わずか（0 < cov < 0.1） | 27,926 | 26,150 | 93.64% | 1,672 |
| 部分（0.1 <= cov < 0.5） | 60,798 | 56,502 | 92.93% | 4,116 |

| 水域被覆が欠測 | 342 | 0 | 0% | 256 |
| **全体** | 3,337,319 | 3,274,665 | 98.12% | 42,790 |

**確認された偏り**: 品質列で除外されたセルの水域被覆は平均0.199で、母集団平均0.056の3.5倍である。除外セルの平均LSTは33.57°Cで最終母数の35.52°Cより約2°C低く、**低温側が優先的に削られる方向**である。

**偏りの規模**: 水域被覆の平均は母集団0.05633に対し最終母数0.05449であり、相対3.3%の減少にとどまる。最も残存率の低い階級（0.5–0.9）でも90.92%が残る。

**0補完方針との関係**: 残存率の凹みは0補完が作ったものではない。水域優位セル135,301のうち**53,955セルは0補完によって初めて最終母数へ残った**もので、0補完が無ければ水域優位セルの残存率は96.32%から56.4%へ落ちる。方針変更は水域の取りこぼしを大幅に**減らした**側である。

**残る凹みの由来**: 最も残存率の低い0.5–0.9の階級は「過半が水域だが閾値0.9に満たない」セルであり、1.2節の「水域と断定できない陸地」に対応する。水域と断定できないセルへ人口0を与える誤りを避けるため、あえて補完せず除外すると決めた範囲であり、**閾値0.9の意図した帰結**である。

**この偏りは分光指数の差し替えでは解消しない**。脱落の出所は品質列（人口・夜間光の有効域）であって投入する指数の選択ではない。また `NDVI`・`NDBI`・`NDWI` は19,633セルで完全に同時にNULLになり（各 `exclusive_null_count` が0）、欠測がバンド個別ではなく観測シーンのフットプリント・雲マスクに由来することを示す。したがって水指数を差し替えても脱落するセルは変わらない。**本節の偏りは解消済みの課題ではなく、結果の解釈時に持ち越す前提条件として扱う**（低温側・水域寄りのセルが母集団からわずかに薄いこと）。

| 変数 | VIF（母数3,274,665） |
|---|---|
| `NDWI` | 34.56 |
| `NDVI` | 32.24 |
| 上記以外の13変数 | いずれも3.3未満 |

NDVI–NDWI のPearson相関は **−0.9719** であり、**分光指数間の共線性は本ドキュメントの母集団で悪化している**（旧観測の母集団では −0.966・VIF 25.0/26.0）。母集団が広がり都心以外を多く含んだことによる性格変化が影響していると考えられるが、本節では実測の記録にとどめる（指数の差し替えは本ドキュメントの対象外）。

#### 判定

建物高さ・人口・夜間光の3つの変更はいずれも意図した方向に効いている。**母集団の性格**についても、建物被覆の平均0.0841・市街地被覆の平均0.2129と、事前の推計（それぞれ0.0833・0.211）にほぼ一致する。

一方で、上記「水域被覆の偏り」のとおり**最終母数は水域寄り・低温側のセルをわずかに薄く含む**。これは欠損値処理の誤りではなく閾値0.9の意図した帰結であり、規模も相対3.3%にとどまるため、現行方針のまま分析へ進む判断とした。ただし**解消済みの課題としてではなく、結果の解釈時に持ち越す前提条件として扱う**。

水指数の共線性（上記「多重共線性」）については、`NDVI` と `NDWI` がどちらもNIRに支配され符号が逆であることに由来する構造的な相関であり、指数の差し替えを含む対処は本ドキュメントの対象外の別課題として扱う。水域をどう表現するかの判断はそちらへ委ねるため、本ドキュメントでは水域セルの抽出条件（閾値0.9）を動かさず、比較の基盤となる母集団を固定した。

### 3.9 分析実行前のモデル前提の精査

3.8節の欠損値処理とは別に、**前処理とモデル構築の前提が成り立っているか**を分析実行の前に確認した。以下は実装の誤りを報告するものではなく（誤りは見つかっていない）、**結果を読むときの前提条件**を明示するものである。

#### 確認して問題がなかった点

- **標準化のリークが無い**: `StandardScaler` は学習データのみで `fit` し、評価データは `transform` のみを適用する（`src.common.regression_models.fit_linear_regression`）
- **土地被覆の単体制約を処理済み**: 7クラスの面積率は**全行で厳密に合計1.0**になる（実測100.0000%）。そのまま投入すると完全な線形従属になるため、参照クラス（ROIで最大の農地 `LULC_CROP_COV`）を除外している（3.6節・`LULC_REFERENCE_COLUMN`）
- **定数列の除外**: `LULC_BARE_COV` はハノイROIのGLCに裸地画素が無く全行で0のため除外され、VIFの偽陽性（`inf`）を防いでいる
- **サンプリングは乱数抽出**（`DataFrame.sample`・シード42）であり、`cell_id` 順の系統抽出ではない
- **Spatial CV のグループ分離**: `GroupKFold` により同一ブロックのセルが学習側と評価側へ分かれることはない

#### Spatial CV のブロックサイズと R² の関係

ブロックサイズを変えて out-of-fold R² を比較した（分析サンプル10万件、RFは診断用に決定木100本。**絶対値ではなくブロックサイズ間の相対変化を読む**ための測定であり、3.5節の本番設定 300本の値とは一致しない）。

| ブロックサイズ | ブロック数 | RF R² | fold間sd | 線形 R² |
|---|---|---|---|---|
| ランダム分割（空間非考慮） | — | 0.7954 | — | 0.6462 |
| **2,700m（本ドキュメントの設定）** | 501 | **0.7596** | 0.045 | 0.6447 |
| 5,400m | 145 | 0.7417 | 0.024 | 0.6319 |
| 8,100m | 72 | 0.6806 | 0.106 | 0.6008 |
| 13,500m | 30 | 0.6748 | 0.126 | 0.5710 |
| 21,600m | 17 | 0.5461 | 0.205 | 0.5228 |

**再現手順**: 上表の各行は `--block-size-m` を切り替えた次のコマンドで再現できる（`--rf-trees 100` が診断設定、サンプル10万件・シード42は既定値）。「ランダム分割（空間非考慮）」の行は同じ実行の `random_split` の値である。**本表は分析ランではなく診断のための測定であり、出力は一時ディレクトリへ出して追跡下には置いていない**（台帳にも載せない）。

```bash
python -m src.analysis.analysis_rq3_limited --block-size-m 5400 --rf-trees 100 --output-dir <一時ディレクトリ>
```

**ブロックを大きくするほど R² が単調に下がる。** LSTのセミバリオグラムでも、2,700m 地点のセミバリアンスは全体分散の69%にとどまり、sillに達するのは15〜30kmである。すなわち**2,700mのブロックでは空間自己相関を断ち切れていない**。

線形モデルとの対比がこれを裏づける。線形モデルはランダム分割0.6462に対し2,700mで0.6447とほぼ変わらない（位置を記憶できないため）のに対し、**RFは0.7954から0.7596へ0.036下がる**。RFだけが近傍の空間的近さから利得を得ていることを示す。さらに「RFが線形を上回る幅」はブロック拡大とともに +0.115（2,700m）→ +0.080（8,100m）→ +0.023（21,600m）と縮む。**RFの優位の相当部分は、非線形性の捕捉ではなく空間自己相関の利用である可能性が高い。**

ただし**低下のすべてが空間リークとは限らない**。ブロックを大きくすると保留域が大きな連続地域になるため、リークの除去と空間的非定常性（地域が変われば説明変数とLSTの関係自体が変わる）が混在する。fold間sdが0.045から0.205へ膨らむのはこのためであり、**大きいブロックでの個々の数値は信頼できない**。信頼できるのは単調に低下するという傾向である。

**結果の読み方（重要）**: いずれの解釈でも帰結は同じで、**本ドキュメントが報告する Spatial CV の R² を「未知の場所への汎化性能」として読んではならない**。同一ROI内・空間的に近い場所への内挿性能として読む。ブロックサイズ自体の見直し（適切なサイズ・緩衝帯の要否）は独立した方法論の判断であり、本ドキュメントの対象外とする。

#### 建物高さ0補完の構造的な従属

`BUILD_H_MEAN == 0` のセルは、`BUILD_COV == 0 かつ BUILD_DEN == 0` のセルと**一致率100.000000%で一致する**（分析サンプルの72.66%）。3.2節の補完規則そのものが `BUILD_COV == 0 AND BUILD_DEN == 0` を判定条件としているため、**補完後の建物高さ列のゼロ部分は他の2つの建物変数から完全に決まる**。

VIFはこれを検出できない（`BUILD_H_MEAN` のVIFは1.72）。VIFが測るのは線形従属であり、ここでの従属は「ゼロか否か」という指示変数の水準で生じているためである。結果として、`BUILD_H_MEAN` の標準化係数・重要度は**「建物の有無」（`BUILD_COV`・`BUILD_DEN` と共有する情報）と「建物がある場合の高さ」を分離できない**。非ゼロ部分の分布は平均5.73m・中央値4.82m・最大137.7m、列全体の歪度は11.1である。**建物高さの寄与の小ささ（5.1節・6.4節）を「高さがLSTに影響しない」と読んではならない。**

#### 目的変数と説明変数の間接的な結合

LSTはUSGS Landsat Collection 2のLevel-2地表面温度プロダクト（`ST_B10`）をスケーリングして用いており（`src.gee.gee_calc_LST.calculate_lst_simple`）、本研究のコード内で植生指数から放射率を算出してはいない。ただし**当該プロダクトの放射率推定が同一シーンの植生指数を用いる場合、`NDVI` と `LST` の間に間接的な代数的依存が生じうる**。RQ1（どの説明変数が支配的か）で植生指数の寄与を論じる際の前提になるため、**プロダクトの算出仕様の確認を要する（本ドキュメント時点では未確認）**。

#### 変数分布の性質

分析サンプルにおけるゼロの割合と歪度は次のとおりで、線形モデルの係数は多くの変数で実質的に「有無」の対比を測ることになる。

| 被覆率ブロック SHAP 合計（`coverage`） | 1.0313 | 1.2828 | +0.2515 |
| `LULC_BUILT_COV` の SHAP（`coverage`） | 0.7798 | 0.9944 | +0.2146 |

**二値化が被覆率型を不当に不利にしているという想定は支持されなかった。** `coverage` の RF R² は土地被覆ソースの解像度を9倍近く上げてもほぼ動かない（-0.0012）。

ただし**ラン10・11 はラン1・4 と標本が事実上別物である**（`cell_id` の重なり 3.10%・2.1節）。2.1節で実測した R² の標本変動（0.0025）と突き合わせると、**上表の2つの R² 差は扱いが分かれる**。

- `coverage` の差 **-0.0012** は標本変動の範囲内であり、**土地被覆ソースの効果として読めない**
- `both` の差 **+0.0102** は標本変動の約4倍で、**標本の入れ替わりだけでは説明が付かない**。ただし母集団も 10,003セル異なり、土地被覆ソースの効果と母集団差は分離できていない（2.1節の測定は母集団を固定しており、母集団が異なる本比較では下限にすぎない）

`spectral` はEsriで未実行であり（脚注[^filter]参照）、フィルタ母数がLULCソースに依存する以上、4.3節の結論を `spectral` 側の解像度依存性にまで拡張することはできない。

### 6.4 建物高さ列の多重共線性（解消済み）

#### 6.4.1 問題の所在

`BUILD_H_MEAN`/`BUILD_H_MAX` を2列とも投入すると VIF は **38.15 / 40.78**（ラン5）となり、慣例的な危険水準 VIF > 10 を大きく超える。直接の原因は2列の Pearson **+0.985**（6.2節）であり、同一の建物ポリゴンから平均と最大を集計している以上、構造的に避けられない相関である。建物高さの0補完（`BUILD_COV == 0 AND BUILD_DEN == 0` のセルへの適用）により「高さ0」の大きなスパイクが2列に共通して生じることも、相関をさらに押し上げている。

**この問題は変数セットの選択とは独立している。** ラン5とラン1・6・7 は同一セル上の評価であり（2.1節）、新規変数の追加・削除と無関係な独立した問題であることが標本統制のうえで確認できる。

> **旧記録との差についての注意**: アーカイブ側では Esri 標本での VIF が GLC 標本より高く出ており（60.2 対 54.8）、これは土地被覆ソースの性質ではなく標本の違いによるものと結論している。本ドキュメントでは `both` 構成を Esri で実行していないため、この点は再測定していない。**「解像度を上げると建物高さの共線性が増す」という読みが誤りであることは変わらない**が、根拠はアーカイブ側の実測である。

#### 6.4.2 4構成の比較（ラン1・5・6・7）

高さブロックの構成だけを差し替えた4構成を、**同一セル上**で評価した（母数・`cell_id` とも完全一致。2.1節）。

| 構成 | 建物高さのVIF | RF R²（Spatial CV） | Linear R²（Spatial CV） | RF重要度（高さ計） | SHAP 平均絶対値（順位） | 標準化係数（順位） |
|---|---|---|---|---|---|---|
| ラン5 `both` | **38.15 / 40.78** | 0.7606（sd 0.0452） | 0.6449 | 0.01034 | 0.0250（11位）/ 0.0256（10位） | **+0.0714（11位）/ −0.1030（8位）** |
| ラン1 `mean` | **1.72** | 0.7604（sd 0.0451） | 0.6447 | 0.00792 | 0.0458（9位） | −0.0260（14位） |
| ラン6 `max` | **1.83** | 0.7606（sd 0.0451） | 0.6448 | 0.00824 | 0.0449（9位） | −0.0308（14位） |
| ラン7 `pc1` | **1.78** | 0.7605（sd 0.0452） | 0.6447 | 0.00816 | 0.0452（9位） | −0.0285（14位） |

順位はそれぞれのランの変数数（`both` は16、他は15）における順位である。

**3つの1列構成すべてで建物高さのVIFが危険水準を大きく下回った**（1.72〜1.83）。

**VIF値そのものの精度**: VIFは標本の取り方だけで、建物高さ列では相対 8.1% 変動する（2.1節）。本ドキュメントのVIFは「危険水準（>10）を大きく超えるかどうか」の判定には十分だが、**ラン間の数ポイントの差を実質的な違いとして解釈してはならない**。3構成の差（1.72〜1.83・幅0.11）もこの範囲にあり、**VIFの大小を採用構成の決め手にはしない**。

**説明力はどの構成でも変わらない。** RF R²（Spatial CV）の差は最大 **0.0002** で、2.1節で実測した R² の標本変動（0.0025）の1/10 未満である（4構成は標本が同一のため標本変動は効かないが、読み取れる差の下限としてこの水準を用いる）。SHAP 上位変数の順位（`NDBI` → `LULC_BUILT_COV` → `POP_DEN_WORLDPOP2020` → `ELEV_MEAN` → `NDVI` → `NDWI`）は4構成で完全に一致し、値の差も 0.001 未満である（たとえば `NDBI` はラン1 0.7025 に対しラン5 0.7017・ラン6 0.7024・ラン7 0.7028）。建物高さブロックがRF重要度に占める割合は 0.79〜1.03% にとどまるため、この一致は当然の結果である。**R²の差を採否の根拠にしてはならない。**

#### 6.4.3 最も重要な所見: `both` の標準化係数は共線性のアーティファクトだった

上表で唯一、構成間に明確な差が出たのは**標準化係数**である。

- ラン5 `both` では `BUILD_H_MEAN` **+0.0714**（11位）と `BUILD_H_MAX` **−0.1030**（8位）という、**大きさが同程度で符号が逆の一対**が現れる。これは分散拡大による典型的な共線性アーティファクトである
- 共線性を解消した3構成では、いずれも係数が **−0.0260〜−0.0308**（14位）へ収束する

**ラン5で `BUILD_H_MAX` が標準化係数の第8位に現れていたのは見かけの効果であり、実際の寄与ではなかった。** これは同一セル上の比較で示された結果であり（標本差では説明できない）、RF重要度・SHAPが一貫して建物高さを小さな寄与（9〜11位・全体の1%前後）と評価していたことと整合する。**線形回帰の標準化係数を主たる解釈に用いなかった従来の判断（6.4.5節）が、事後的に正しかったことが確認できる。**

**旧記録との差異（重要）**: アーカイブ側（旧ラン11〜13）は「共線性を解消すると係数が**ほぼ0へ収束**する」（−0.0028〜−0.0110）と記述していた。**本ドキュメントの標本では収束先がほぼ0ではなく、3構成とも −0.026〜−0.031 の一貫した負値である。** 大きさは依然として最下位級（15変数中14位）で解釈の主役にならない点は変わらないが、「ほぼ0」と要約すると実測より強い主張になる。**「共線性を解消すると符号の逆転が消え、小さい負値に収束する」と読むのが正確である。** この負値を冷却効果として解釈できない理由は5.7節・3.9節を参照する。

#### 6.4.4 採用構成: `mean`（セル内の平均建物高さ）

3つの1列構成は統計的にほぼ等価であるため、**VIF・解釈可能性・実装上の但し書き・情報損失**で判断した。**採用は `mean` を維持する**（`--building-height` の既定値も変更しない）。

| 判断軸 | 評価 |
|---|---|
| VIF | `mean` 1.72 が最小。ただし3構成の差（幅0.11）は標本変動の範囲内であり、決め手にはしない（6.4.2節） |
| 解釈可能性 | **`mean` は「セル内の平均建物高さ」として物理的な意味が直接読める。** 都市キャノピー高さに対応する標準的な都市形態パラメータであり、`urban_structure_parameters.md` の定義をそのまま使える |
| 実装上の但し書き | **`mean` は生の観測列であり、主成分化に伴う但し書き（fit範囲・符号正規化・fold内fitの是非・無次元の合成軸）が一切不要**。結果の再現・解釈に必要な前提が最も少ない |
| 情報損失 | `pc1` は2列の情報を99.25%保持するが（寄与率 0.99249・loadings は両列とも +0.707）、`mean` を採っても説明力・重要度・SHAPは `pc1` と区別できない（6.4.2節）。情報損失は実測上ゼロと見なせる |

**既定値見直しの要否**: 032305 の標本で4構成を測り直した結果、**採用構成を変更する根拠は得られなかった**。上表の判断軸のうち順位が入れ替わったものは無く、SHAP では `mean`（0.0458）が `max`（0.0449）・`pc1`（0.0452）をわずかに上回る（旧記録では `max` がわずかに上回っていた）。差は最大でも 0.0009 で、6.4.2節と同じ下限（2.1節で実測した単一変数の SHAP の標本変動・最大 0.1366）を2桁下回る。**この入れ替わりを採否の根拠にはしない**（2.1節のとおり fold間sd 自体が標本で2倍近く動くため、物差しには使わない）。

**`max` を採らなかった理由**: `max` はセル内の単一の建物に値が左右されるため外れ値の影響を受けやすく、平均高さより頑健性が劣る。SHAP・VIF・R² のいずれでも `mean` に対する優位が実測されない。

**`pc1` を採らなかった理由**: 無次元の合成軸であり、係数・SHAPの値を物理量として読めない。加えて、標準化統計・loadings・符号の向き・fitの範囲という4つの但し書きが結果の解釈に常に付随する。情報保持の利点（99.25%）に見合う実益が実測で確認できなかった。

**Spatial CV の fold 内で PCA を fit する案は採用しなかった**（`pc1` 自体を採らなかったため実質的に無効化されたが、判断の記録として残す）。全体fitとfold内fitの差は「高さ2列の標準偏差の比」だけに限定される。模擬データでの実測 ΔR² は線形回帰 2.6e-08〜2.6e-06・RF 1.7e-05〜2.2e-04 であり、最大値でもラン1のfold間sd（0.0451）の約1/200、かつRF自身の乱数シードによる振れ幅（1.6e-03）より小さい。`src/common/analysis_runs.py`（Satellite Only と共用）へfold内変換の仕組みを持ち込むコストに見合わないと判断した。

> **上記の ΔR² の出典**: 計画段階に複数条件（分割の偏らせ方・乱数シード）で実施した**模擬データによる実測**であり、本リポジトリには再現用の成果物を残していない。**リポジトリ内で再現できるのは線形回帰の1条件のみ**で、`tests/analysis/test_analysis_rq3_limited.py` の `test_whole_sample_fit_agrees_with_fold_internal_fit` が `ΔR² < 1e-4` と `corr(fold PC1, 全体 PC1) > 1 - 1e-6` を固定している（RFは自身のシード変動に埋もれるためテスト対象外）。**RF側の範囲を再検証する場合は測り直しが必要である。**

#### 6.4.5 標準化係数を主たる解釈に用いてよいかの判断

**建物高さブロックについては解消した。** ラン1・6・7 では建物高さのVIFが 1.72〜1.83 と危険水準を大きく下回り、係数の解釈を妨げる共線性は無い。ただし6.4.3節のとおり収束後の係数は小さい負値であり、かつ3.9節の構造的従属により「建物の有無」と「高さ」を分離できないため、**この係数を建物高さの効果として読むことはできない**。

**モデル全体については解消していない。** 全ランで `NDVI` 32.2・`NDWI` 34.6 が危険水準に残る（6.1節・6.5節）。分光指数の共線性は本ドキュメントの対象外であり、**モデル全体として標準化係数を主たる解釈に用いてよい状態にはなっていない**。Satellite Only の既存結果と同じ方針を継続し、**変数重要度の主たる解釈は Random Forest の SHAP と Permutation 重要度に基づき、線形回帰の標準化係数の絶対値順位は補助的な情報として扱う**（RF の不純度ベース重要度も単独では用いない・5.1節）。

#### 6.4.6 検討対象外とした案

以下の2案は着手時に却下根拠つきで検討対象外としたものであり、記録として残す。

- **`BUILD_COV`/`BUILD_DEN` の除外**: 建物高さのVIFの直接の原因は高さ2列どうしの相関（+0.985）であり、`BUILD_COV` × `BUILD_H_MAX` の +0.612・`BUILD_COV` × `BUILD_H_MEAN` の +0.578 はそれより弱い。実際、ラン1・6・7 は `BUILD_COV`・`BUILD_DEN` を残したまま VIF が 1.72〜1.83 まで下がっており、**この2列を除外する必要が無いことが実測で確認された**
- **0補完の再設計**: 0補完をやめると「建物はあるが高さが得られない」セルと「建物が無い」セルを区別できなくなり、フィルタで大量のセルが脱落して有効域が大きく縮む（データセット全体の74.4%が補完対象・3.2節）。有効域の縮小は本シナリオの評価意図に反する

**相関行列は建物高さ構成に依らず一定である。** 対象列は「拡張後の全候補列」で固定されており（3.2節）、ラン1・5・6・7 の相関行列は一致する。したがって6.2節の記述は構成の違いに影響されない。

### 6.5 分光指数間の共線性

`NDVI`・`NDWI` の VIF（ラン1で 32.24・34.56）は全ランで危険水準に残る。直接の原因は `NDVI` × `NDWI` の Pearson **-0.972**（6.2節）であり、両者がどちらもNIRに支配され符号が逆であることに由来する構造的な相関である。

**本ドキュメントの母集団では旧観測より悪化している**（旧観測では VIF 25.0・26.0、Pearson -0.966）。母集団が約1.76倍になり都心以外を広く含んだことによる性格変化が影響していると考えられるが、切り分けは行っていない。建物高さと同様の構成比較（どちらか1本に絞る・主成分化する）は未実施であり、**分光指数の共線性は未解決のまま残る**（7節）。

### 6.6 VALID_GIS_MASK を主結果に課さなかった判断の妥当性

3.3節の実測（`VALID_GIS_MASK == 0` が全件 `no_gis_feature` で `missing_gis_data` が0件）を踏まえ、主結果ではこの条件を課さなかった。ただしこの「0件」という実測は、建物パラメータテーブルの結合が正準グリッド全体に対して完全であることの確認に過ぎず、GBAが現地の建物を漏れなく検出できていることまでは保証しない（3.2節・3.3節）。この限界を踏まえてもなお、`VALID_GIS_MASK == 0` のセルを観測結果として0扱いする判断自体は妥当と考えられる。

台帳の比較から、この判断により Spatial CV R²（RF）はラン1 **0.7604** 対 ラン2 **0.7097** と、有効域全体を対象にした方が高い説明力を示す（母数は 3,274,665 対 1,309,830）。これは「Limitedシナリオが農地・水域を含む多様な土地被覆下でLSTをどれだけ説明できるか」という評価意図と整合する。

**ただし線形モデルでは差がほぼ無い**（0.6447 対 0.6449）。RF のみで差が出ることは、ラン2の母集団が市街地へ偏り空間的な多様性を失うことと整合する。またラン1とラン2は標本が別物であるため（重なり 3.02%）、差の大きさそのものは効果量として扱わない。

### 6.7 Satellite Only との参考比較（保留）

**本ドキュメントの観測（032305）に対応する Satellite Only のランが存在しないため、参考比較を保留する。** 比較相手の [satellite_only_analysis_results_cellbased.md](satellite_only_analysis_results_cellbased.md) は観測 032329 に基づいており、観測・母数の定義・建物高さの帰属方式・nodata 方針のいずれもが本ドキュメントと異なる。**観測をまたいだ数値比較は成立しない**（1節）。

## 7. 今後の研究の方向性

- **Satellite Only の観測移行と定量比較**: 6.7節のとおり参考比較を保留している。Satellite Only を 032305 へ移行し、同一観測・同一格子のうえで改善幅を評価する。**本ドキュメントの結論のうちシナリオ間比較に関わる部分は、これが完了するまで未確定である**
- **分光指数間の共線性の解消**: 建物高さの共線性は `--building-height mean` の採用で解消したが（6.4節）、`NDVI` 32.2・`NDWI` 34.6 の VIF は未解決のまま残り、旧観測より悪化している（6.5節）。両者の Pearson は −0.972 であり、モデル全体として標準化係数を主たる解釈に用いるには、建物高さと同様の構成比較が要る
- **建物高さの「有無」と「高さ」の分離**: 3.9節のとおり `BUILD_H_MEAN` のゼロ部分は `BUILD_COV`・`BUILD_DEN` から完全に決まり、寄与を分離できない。「建物がある場合の高さ」を測る構成（非ゼロセルに限定した評価・有無を表す指示変数の分離）を別途検討する。**現状の寄与の小ささを高さの無影響と読まないこと**
- **Full シナリオへ進む**: 測量GISを加えた Full が Limited をどれだけ改善するかを、同じ共通モジュール（`src.common.*`, `src.common.analysis_runs`）を再利用して確認する
- **採用構成の他シナリオへの波及**: Limited で `mean` を採用したことを踏まえ、Full シナリオでも同じ構成を用いるかを、測量GIS由来の建物高さの精度と合わせて判断する
- **ソース差し替え軸の標本統制**: 2.1節のとおり、土地被覆・人口のソース差し替えランは母数がわずかに違うだけで標本がほぼ別物になる（重なり 3.1%・偶然一致水準 3.05%）。**Esri `both` の +0.0102 と人口ソースの 0.0122〜0.0129 は標本変動（0.0025）を超えており、母集団差とソース効果を分離すれば実質的な差が残る可能性がある。** ソース間を厳密に比較するには、共通するセルに限定して評価する仕組みが要る。人口ソース軸については、フィルタ列に3版すべてを含める設計への変更も選択肢である（母数差は 865セル・0.0264%）
- **標本変動の測定範囲の拡張**: 2.1節の実測は母集団を固定した3標本にとどまる。母集団自体が変わる比較（ソース差し替え・フィルタ条件）に適用できる変動幅は測れていないため、ここで得た値は下限として扱っている。共通セルに限定した評価と併せて設計する
- **モデル説明力の指標間の不一致**: 5.1節のとおり RF の不純度ベース重要度だけが `LULC_BUILT_COV` を首位とし、SHAP・Permutation と食い違う。取りうる値が少ない変数での不純度ベース重要度の挙動を確認し、報告する指標を明確に定める
- **被覆率型変数の位置づけの再検討**: 4.3節・5.5節のとおり、被覆率型は RF では分光指数を上回らず、土地被覆ソースの解像度を上げても結論は変わらなかった。一方で線形モデルでは被覆率型が上回る。`both` 構成の分光単体に対する改善が 0.014（RF・GLC）と小さいことも踏まえ、被覆率型を最終的な変数セットに含めるかどうかを、モデルの簡潔性とのトレードオフとして別途判断する
- **LSTプロダクトの算出仕様の確認**: 3.9節のとおり、Level-2 地表面温度プロダクトの放射率推定が同一シーンの植生指数を用いる場合、`NDVI` と `LST` の間に間接的な代数的依存が生じうる。RQ1 で植生指数の寄与を論じる前提となるため確認を要する
- **GBAの有効カバレッジそのものの検証**: 3.3節で指摘したとおり、`missing_gis_data == 0` はテーブル結合の完全性のみを示し、GBAが現地の建物を漏れなく検出できているかは未検証である。別途、現地測量データや高解像度衛星画像との突合による検証を検討する
- **30mでの観測日拡張**: Satellite Only と同様、複数観測日が揃った時点で同じ経路での複数日比較を検討する
- **結果ドキュメントの共通様式の規約化**: 本ドキュメントで用いた台帳形式（列定義・数値の正本の置き方・標本統制の明示）を規約として定め、`satellite_only_analysis_results_cellbased.md` へも適用することを別途検討する
