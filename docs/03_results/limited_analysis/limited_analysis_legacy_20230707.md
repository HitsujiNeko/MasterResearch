## 2. 分析ラン一覧（台帳）

### 2.1 台帳の読み方（比較してよい組み合わせ）

**数値を直接比較してよいかどうかは、母数だけでなく標本まで揃っているかで判断する。** `sample_dataset` は母数に対して位置指定で10万件を抽出するため、**母数が数百セル違うだけで抽出位置が総入れ替えになる**。偶然一致の基準値は 10万 / 3,274,665 ≒ 3.05% であり、重なり率がこの水準にとどまるランどうしは事実上独立な2標本とみなす。

| 比較軸 | 対象ラン | 母数 | 標本の重なり | 標本統制 |
|---|---|---|---|---|
| 変数セット | 1・3・4 | 3,274,665（一致） | 100% | **あり** |
| 建物高さ構成 | 1・5・6・7 | 3,274,665（一致） | 100% | **あり** |
| 人口ソース | 8 対 9 | 3,273,800（一致） | 100% | **あり** |
| 土地被覆ソース | 10 対 11 | 3,284,668（一致） | 100% | **あり** |
| 人口ソース | 1 対 8・9 | 3,274,665 対 3,273,800 | 3.08% | **なし** |
| 土地被覆ソース | 1 対 10・11 | 3,274,665 対 3,284,668 | 3.10% | **なし** |
| フィルタ条件 | 1 対 2 | 3,274,665 対 1,309,830 | 3.02% | **なし**（意図的） |
| 水指数構成 | 12・13・14・15 | 3,274,657（一致） | 100% | **あり** |
| データセットの世代 | 1 対 12 | 3,274,665 対 3,274,657 | 13.46% | **なし** |

- **変数セット軸・建物高さ軸は同一セル上の比較である。** 非NULLを要求するフィルタ列を変数セット・建物高さ構成に依らず一定にしている設計による（3.2節・3.3節）。本ドキュメントで最も統制の効いた比較であり、差を実質的な違いとして読んでよい
- **ソース差し替え軸（人口・土地被覆）は統制されていない。** フィルタ列は「選択した人口版のみ」を要求する設計であり（投入しない版の欠測で母数を減らさないことを優先した）、土地被覆は入力データセット自体が別である。**ソース間の差は符号を含めて実質的な違いとして読んではならない**（5.5節・5.6節）
- **同一ソース群の内部（8対9・10対11）は統制されている。** 人口2版の比較・Esri内の変数セット比較は同一セル上で行われている
- **ラン2（gismask）は母数が大きく異なる。** `VALID_GIS_MASK == 1` の限定によるものであり、ラン1との比較はフィルタ条件の効果を見るためのものである（6.6節）
- **水指数軸（ラン12〜15）は同一セル上の比較である。** 非NULLを要求する分光指数列を水指数の構成に依らず4列（MNDWI を含む）で固定している設計による（3.3節）
- **データセットの世代をまたぐ比較（ラン1対12）は統制されない。** 構成（`both`・`mean`・`ndwi`・WorldPop2020）は同一だが、母数が8セル違うため標本が入れ替わる（重なり 13.46%）。RF R²（Spatial CV）は 0.7604 で一致し、線形 R² は 0.6447 → 0.6496（+0.0049）と標本変動（0.0033）をわずかに超えるが、標本と母集団の差を分離できないため世代の効果として読まない

#### 標本変動の実測

ラン間の差を「実質的な違い」と読んでよいかの物差しとして、**標本の入れ替わりだけで各指標がどれだけ動くか**を実測した。母集団（3,274,665セル）とラン構成をラン1に固定し、`--random-state` だけを 42（ラン1）・43・44 と変えて3標本を抽出している。3標本の相互の重なりは 3.01〜3.16% で偶然一致水準（3.05%）と一致し、独立な標本とみなせる。

**本測定は分析ランではなく診断であり、出力は一時ディレクトリへ出して追跡下には置いていない**（台帳にも載せない。3.9節のブロックサイズ診断と同じ扱い）。再現コマンドは次のとおり。

```bash
python -m src.analysis.analysis_rq3_limited --random-state 43 --output-dir <一時ディレクトリ>
```

**このコマンドは旧世代のデータセット・当時のコードでのみ上表を再現できる。** 現行のスクリプトは既定の水指数が `none` に変わり、MNDWI 列の無い旧世代のデータセットを拒否するため、そのまま実行すると別の構成・別の母数での測定になる（1.4節）。

| 線形 R²（Spatial CV） | 0.6430〜0.6463 | **0.0033** |

**読み方**（3標本の測定）:

- **3標本の R² の最大差は 0.003 程度**だった。ただし下の20シードの実測では、範囲はこの3〜4倍に広がった。3標本の最大差は変動の幅を小さく見積もっており、標本統制の無い比較の物差しには下の20シードの値を使う。6.5.5節の事前基準（R² 低下 ≤ 0.003）など、記録時にこの値を物差しにした記述はそのまま残している
- **SHAP の標本変動は大きい**（`NDWI` で 0.1366、`LULC_BUILT_COV` で 0.0842）。SHAP の差を論じるときは 0.1 程度の変動を織り込む。SHAP 上位の順位も第4位までは3標本で安定するが、**第5・6位（`NDVI` と `NDWI`）は入れ替わる**
- **fold間sd 自体が標本で2倍近く動く**（0.0263〜0.0451）。**fold間sd をラン間の差の物差しに使わない**
- VIF は分光指数で相対 0.6%、建物高さで相対 8.1% 変動する。**危険水準（>10）を超えるかの判定には十分だが、数ポイントの差は読まない**
- **この測定は母集団を固定している。** 母集団自体が異なる比較（ソース差し替え軸・フィルタ条件軸）では、ここで測った変動は**下限**にすぎない

**20シードでの実測（主採用の観測・共通集合）**: 8.6節の比較のために、主採用の観測 032358 の共通評価セル集合（3,422,216セル・8.6節）から、乱数シード 42〜61 の20標本（各10万件）を抽出して Spatial CV だけを回した。シードは標本抽出と RF の乱数の両方に使っている（上の3標本の測定と同じ）。上の測定とは**母集団（ラン1の 3,274,665セル 対 共通集合）・観測（032305 対 032358）・構成（`ndwi` 対 `none`）・シード数（3 対 20）がいずれも異なる**。ランダム分割・VIF・SHAP は測っていない（反復では Spatial CV だけを回すため）。数値の正本は `data/output/common_evaluation/20220906_032358/repeated_comparison_evaluation_cells_seed42_results.json` である（fold間sd の範囲は同じディレクトリの `_folds.csv` から求めた）。

| 指標（Spatial CV） | 衛星＋公開GISデータの採用構成：平均 / シード間 sd / 範囲 | 衛星データのみ：平均 / シード間 sd / 範囲 |
|---|---|---|
| RF R² | 0.8375 / 0.0024 / 0.8327〜0.8432（幅 0.0105） | 0.7514 / 0.0019 / 0.7480〜0.7557（幅 0.0077） |
| 線形 R² | 0.7638 / 0.0029 / 0.7583〜0.7701（幅 0.0118） | 0.6899 / 0.0028 / 0.6830〜0.6937（幅 0.0107） |
| RF の fold間sd | 0.0028〜0.0217 | 0.0035〜0.0271 |
| 線形の fold間sd | 0.0059〜0.0360 | 0.0060〜0.0299 |

シード間 sd は20シードの値の不偏標準偏差（ddof=1）、fold間sd は各シードの5 fold の母標準偏差（ddof=0。各ランの `results.json` の `r2_std` と同じ定義）であり、定義が異なる。非空ブロック数は 500〜503、分散0で除外された列は20シードとも `LULC_BARE_COV` だけだった。

**読み方**（20シードの測定）:

- **単一ランの R² の標本変動は、シード間 sd で 0.002〜0.003 である。** 範囲（最大と最小の差）は 0.008〜0.012 に達する。**独立な2標本のランどうし（標本統制の無い比較）では、R² の差が 0.01 程度までなら標本の入れ替わりだけで生じうるものとして読む**（独立な2標本の差の sd は単一ランの sd の約1.4倍で、0.003〜0.004 になる）。この値は 032358 の共通集合で測ったものであり、032305 のランどうしへ当てはめるのは外挿である
- **同じ標本の上での比較（標本統制のある比較）では、差の変動はこれより小さい。** 8.6節のシナリオ間の差（RF R²）のシード間 sd は 0.0015 であり、2シナリオの単一ランの sd（0.0019・0.0024）を独立に合成した値（約0.0031）の半分ほどである。2つの構成が同じ標本の変動を共有し、差を取ると一部が打ち消し合うためである。標本統制のある軸（変数セット・建物高さ・水指数）の差の物差しとしては、単一ランの変動は保守的（大きめ）である
- **fold間sd は20シードで1桁近く動く**（RF で 0.0028〜0.0271）。3標本の測定の「fold間sd をラン間の差の物差しに使わない」をより強く裏づける

### 4.2 Spatial CV

R² は台帳（2節）に記載する。random split から Spatial CV への変化は **RF で -0.036〜-0.083**（全ランで低下）、**線形で +0.005〜-0.020**（ラン3・8・9 はわずかに上昇）である。fold間の標準偏差（RF）は 0.014〜0.046 である。

**低下幅はランによって2倍以上ちがう。** 最大はラン10（`coverage`・Esri、-0.083）、最小はラン6（建物高さ `max`、-0.036）であり、被覆率のみの構成で低下が大きい。**線形モデルではラン3・8・9 で Spatial CV のほうがわずかに高くなる**が、いずれも fold間sd（0.042〜0.053）よりはるかに小さく、符号を意味のある差として読まない。

**この低下の小ささを「空間自己相関による過大評価が無い」根拠として読んではならない。** ブロックサイズを変えた実測（3.9節）が示すとおり、ブロックサイズ 2,700m では LST の空間自己相関を断ち切れておらず、ブロックを広げると R² はさらに単調に低下する。**低下が小さいのは過大評価が無いからではなく、ブロックが小さく学習側と評価側が空間的に近いままであるためと解釈するのが妥当である。** 台帳の R² は遡及修正せず、この読み方の注意に留める（[spatial_cv_design_results.md](../spatial_cv_design_results.md) 5章）。

### 4.3 変数セット別の比較

ラン1・3・4 は母数（3,274,665）・ブロック数（501）・建物高さ構成（`mean`）がすべて一致し、**変数セットの比較は同一セル上で行われている**（2.1節）。

| 変数セット | RF R²（Spatial CV, GLC） | 線形 R²（Spatial CV, GLC） | RF R²（Spatial CV, Esri） | 線形 R²（Spatial CV, Esri） |
|---|---|---|---|---|
| `spectral` | 0.7468 | 0.5944 | 未実行[^filter] | 未実行[^filter] |
| `coverage` | 0.6741 | **0.6105** | 0.6729 | 0.5874 |
| `both` | **0.7604** | 0.6447 | **0.7706** | **0.6338** |

- **RF では分光指数が被覆率型を上回る。** `spectral`（0.7468）が `coverage`（0.6741）を **0.073** 上回る。母数・標本が完全に一致するため、この差は母数差では説明できない
- **線形モデルでは向きが逆になる。** `coverage`（0.6105）が `spectral`（0.5944）を **0.016** 上回る。**したがって「分光指数が被覆率型を上回る」はモデルを指定せずに主張できない**
- **`both` が両ソースとも最良である。** 分光指数と被覆率型は補完的な情報を持つ。ただし `both` の `spectral` に対する改善は GLC で 0.014（RF）と小さい
- Esri では `coverage` に対する `both` の改善が 0.098（RF）と大きいが、**Esri での `spectral` が未実行**であるため、分光指数単体との比較はできていない

**結論の位置づけ**: 本節の比較は標本統制されており、GLC の3構成間の差は実質的な違いとして読んでよい。ただし**RFと線形モデルで向きが一致しない**ため、「分光指数が被覆率型を上回る」という主張は **RF に限定した観察**として扱う。線形モデルの係数は多重共線性の影響下にあり（6.5節）、この向きの違い自体も共線性を含めて解釈する必要がある。

### 5.6 人口密度データソースの差し替え

| 版 | 人口概念 | 観測年 | SHAP寄与 | VIF | RF R²（Spatial CV） |
|---|---|---|---|---|---|
| WorldPop2020（ラン1） | 居住人口 | 2020 | **0.3771** | 1.91 | **0.7604** |
| LandScan2020（ラン8） | 実効人口 | 2020 | 0.1373 | 1.51 | 0.7475 |
| LandScan2023（ラン9） | 実効人口 | 2023 | 0.1727 | 1.57 | 0.7482 |

**解釈上の制約（2点）**:

1. **人口概念の差と観測年のずれを1つの比較で分離できない。** WorldPop2020 と LandScan2020 の比較は観測年を固定して概念を変え、LandScan2020 と LandScan2023 の比較は概念を固定して年を変える。しかし WorldPop はベトナムの提供が2020年までであり、居住人口側で年を振ることができないため、「概念×年」の2元配置は成立しない。したがって WorldPop が最も高い寄与を示したことを「居住人口のほうが実効人口よりLSTをよく説明する」と読むことはできない
2. **WorldPop と LandScan の間は母数・標本が揃っていない**（3,274,665 対 3,273,800、差 865セル・0.0264%。標本の重なり 3.08%）。フィルタ列は選択した人口版のみを要求する設計であり、**人口ソース軸のみ母数統制されていない**（2.1節）

WorldPop と LandScan の RF R² 差（0.0129 / 0.0122）は 2.1節で実測した標本変動（0.0025）の約5倍であり、**標本の入れ替わりだけでは説明が付かない**。ただし母数も異なるため、人口概念の差・観測年・母集団差を分離できない（上記の制約1・2）。

**ラン8とラン9（LandScan 2版どうし）は母数・標本とも完全に一致する**ため、この2つの比較のみ統制されている。SHAP 寄与は 0.1373 → 0.1727 と2023年版のほうが高い。**この2ランは標本が同一のため、2.1節で測った標本変動はそのままの物差しにはならない**（母集団を固定して標本を振った測定であり、標本の入れ替わりが起きない比較では効かない）。6.4.2節と同じく**読み取れる差の下限**として用いると、SHAP の差 0.0353 は下限（単一変数で最大 0.1366）を、RF R² の差（0.7475 → 0.7482、0.0007）は下限（0.0025）をいずれも下回る。**どちらも実質的な違いとして読める水準にない。**

### 5.7 符号の解釈

ラン1の標準化係数（絶対値の大きい順）は次のとおり。

| 変数 | 標準化係数 | 変数 | 標準化係数 |
|---|---|---|---|
| `NDWI` | −0.4395 | `NTL_MEAN` | +0.0927 |
| `NDVI` | −0.4041 | `LULC_TREE_COV` | −0.0570 |
| `LULC_BUILT_COV` | +0.2666 | `LULC_WETLAND_COV` | −0.0440 |
| `NDBI` | +0.2408 | `LULC_RANGE_COV` | +0.0329 |
| `LULC_WATER_COV` | −0.2130 | `ROAD_DEN` | +0.0310 |
| `POP_DEN_WORLDPOP2020` | +0.1207 | `BUILD_H_MEAN` | −0.0260 |
| `ELEV_MEAN` | −0.1128 | `BUILD_DEN` | −0.0233 |
| `BUILD_COV` | +0.0998 | | |

- **植生・水域が冷却、建築・道路・人口・夜間光が昇温**という直感的に妥当な符号関係を示す。`NDVI`・`NDWI`・`LULC_TREE_COV`・`LULC_WATER_COV` が負、`NDBI`・`LULC_BUILT_COV`・`BUILD_COV`・`ROAD_DEN`・`POP_DEN_WORLDPOP2020`・`NTL_MEAN` が正である
- **ただし `NDVI`（−0.4041）・`NDWI`（−0.4395）が係数の第1・2位を占めるのは共線性のアーティファクトである**（6.5.3節）。共線性を解消した採用構成（ラン13）では `NDVI` の係数は +0.0112 とほぼ0になり、冷却側の線形効果は主に `LULC_WATER_COV`（−0.2638）が担う。**`NDVI`・`NDWI` の符号と大きさを植生・水域の冷却効果として読んではならない**
- `ELEV_MEAN` の係数が負（標高が高いほどLSTが低い）であるのは、標高上昇に伴う気温低減という一般的な傾向と整合する
- **建物系のうち `BUILD_H_MEAN`（−0.0260）と `BUILD_DEN`（−0.0233）は負である。** 係数の絶対値は下位2つであり、**建物高さ・棟数密度の符号を冷却効果として解釈してはならない**。3.9節のとおり `BUILD_H_MEAN` のゼロ部分は `BUILD_COV`・`BUILD_DEN` から完全に決まるため、建物ブロック内で寄与の配分が定まらない
- **符号関係として意味を持つのは `NDBI`・被覆率・道路・標高・人口・夜間光である。** 建物高さの符号については6.4節、`NDVI`・`NDWI` については6.5節の構成比較を参照する

## 7. 今後の研究の方向性

- **シナリオ間比較の標本統制（032358 は実施済み）**: 主採用の観測 032358 では、両シナリオに共通する評価セルと fold で比較した（8.6節）。残る課題は次のとおりである。(1) 分光指数の扱いがシナリオ間で異なる点は、分光指数を揃えた感度分析で確かめ、主結果は採用構成どうしの比較のままとした（8.6.6節。30m のみ）。(2) 032305 では共通評価セルでの比較をしていない（6.7節は参考比較のまま）。(3) Esri 版・測量建物置き換えは共通集合に含めていない（[analysis_workflow.md](../../02_methods/analysis_workflow.md) 5.3.3節）。測量GIS範囲は全域の共通集合には含めず、範囲別の評価セルで比較した（[survey_area_comparison_results.md](../survey_area_comparison_results.md) 7.6節）
- **主採用の観測・採用構成での他の比較軸の測り直し**: 分光指数の共線性は `--water-index none` の採用で解消したが（6.5節）、変数セット・建物高さ・人口・土地被覆ソースの各軸（ラン2〜11）は旧世代のデータセットと `ndwi` 構成による結果のままであり、水指数の構成比較（ラン12〜15）も旧採用の観測による。主採用の観測（8章）の通常ランは採用構成（ラン13 相当）だけである（共通評価セルでは、分光指数を揃えた感度分析として `ndwi` も実行した・8.6.6節）。採用構成を前提に各軸の結論（特に変数セット軸の「分光指数が被覆率型を上回る」・4.3節）が変わらないかを、主採用の観測で測り直す。Esri 版データセットの再生成も含む
- **主採用の観測で R² が上がった要因の切り分け**: 8.5節のとおり、旧採用の観測と比べて R² は標本変動をはるかに超えて上がったが、母集団（カバレッジ）の違いと観測条件（気象・都心と郊外の LST 差）の違いを分離していない。2観測に共通するセルへ限定した評価で切り分ける
- **比較用の乾季の観測での実行**: [observation_selection.md](../../02_methods/observation_selection.md) 8.5節の比較用の観測 `2024-11-30T03:23:36` は未実行である（指標の再エクスポートが先に要る）
- **衛星データのみの水指数の扱い（判断済み）**: 衛星データのみは分光指数3変数のままとし、`NDWI` を外した2変数に揃える比較は行わない（8.6.6節）。3変数構成は同じ `NDVI` × `NDWI` の共線性を持つため（6.7節）、衛星データのみでもこの2列の係数・寄与を個別に解釈しない
- **`NDWI` の除外で失われた成分の意味**: 6.5.4節の恒等式から、`NDWI` が `NDVI`・`NDBI` と重ならない成分は「緑/赤の比」と読める。この成分が R² の低下（RF 0.004〜0.012）を担っているが、物理的な意味（植生の種類・水の濁り等）は未検証である
- **`NDVI` の線形効果と RF 上の寄与の食い違い**: 採用構成で `NDVI` の標準化係数がほぼ0になる一方、RF では SHAP 5位の寄与を持つ（6.5.3節）。非線形な関係か、線形部分を土地被覆率が吸収しているのかを SHAP 依存図等で確認する
- **90m・300m の衛星指標テーブルの再生成**: 032305 の idx テーブルは30mのみ新世代へ作り直した（3.10節）。RQ2 のスケール検討で90m・300mを使う前に再生成する
- **建物高さの「有無」と「高さ」の分離**: 3.9節のとおり `BUILD_H_MEAN` のゼロ部分は `BUILD_COV`・`BUILD_DEN` から完全に決まり、寄与を分離できない。「建物がある場合の高さ」を測る構成（非ゼロセルに限定した評価・有無を表す指示変数の分離）を別途検討する。**現状の寄与の小ささを高さの無影響と読まないこと**
- **付録の測量建物置き換え（余裕があれば）**: 衛星＋公開GISデータの建物の変数を測量GIS由来に置き換えたときに結果がどう変わるかを、同じ共通モジュール（`src.common.*`, `src.common.analysis_runs`）を再利用して確認する
- **採用構成の他シナリオへの波及**: 衛星＋公開GISデータで `mean` を採用したことを踏まえ、付録の測量建物置き換えでも同じ構成を用いるかを判断する（測量GISは高さ属性を持たないため、建物高さは公開GIS由来のまま）
- **ソース差し替え軸の標本統制**: 2.1節のとおり、土地被覆・人口のソース差し替えランは母数がわずかに違うだけで標本がほぼ別物になる（重なり 3.1%・偶然一致水準 3.05%）。**Esri `both` の +0.0102 と人口ソースの 0.0122〜0.0129 は標本変動（0.0025）を超えており、母集団差とソース効果を分離すれば実質的な差が残る可能性がある。** 共通するセルに限定して評価する仕組みは用意した（[analysis_workflow.md](../../02_methods/analysis_workflow.md) 5.3.3節）。032358 の共通評価セルは人口3版の有効条件を重ねて作っており、人口ソース間の比較にもそのまま使える（未実施）。ただし LandScan2020 と LandScan2023 の有効母集団は完全に一致する（8.6.2節）。土地被覆ソース軸は 032358 の Esri 版データセットが未生成で、共通集合に含めていない
- **標本変動の測定範囲の拡張**: 2.1節に、032358 の共通集合での20シードの実測を加えた。単一ランの R² の範囲は 0.008〜0.012 と、3標本の最大差（0.003程度）の3〜4倍あった。ただしどちらも母集団を固定した測定であり、母集団自体が変わる比較（ソース差し替え・フィルタ条件）に適用できる変動幅は測れていない。また、3標本の物差し（0.003）で判断した過去の記述（6.5.5節の事前基準など）は記録時のまま残しており、20シードの物差しで読み直すかは別途判断する
- **モデル説明力の指標間の不一致**: 5.1節のとおり RF の不純度ベース重要度だけが `LULC_BUILT_COV` を首位とし、SHAP・Permutation と食い違う（032305 のラン13でも同じ）。主採用の観測（8.4節）ではこの食い違いが現れず、3指標とも `NDBI` を首位とする。取りうる値が少ない変数での不純度ベース重要度の挙動を確認し、報告する指標を明確に定める
- **被覆率型変数の位置づけの再検討**: 4.3節・5.5節のとおり、被覆率型は RF では分光指数を上回らず、土地被覆ソースの解像度を上げても結論は変わらなかった。一方で線形モデルでは被覆率型が上回る。`both` 構成の分光単体に対する改善が 0.014（RF・GLC）と小さいことも踏まえ、被覆率型を最終的な変数セットに含めるかどうかを、モデルの簡潔性とのトレードオフとして別途判断する
- **LST の放射率と NDVI の依存**: 確認済み。LST は同じシーンの NDVI から放射率を求めており、依存を外した対照でも平均 |SHAP| の上位 5 変数の順位は変わらなかった（下位や他の指標では一部が動いた）。NDVI の寄与の大きさは限界として扱う（3.9節・[lst_emissivity_sensitivity_results.md](../lst_emissivity_sensitivity_results.md)）
- **GBAの有効カバレッジそのものの検証**: 3.3節で指摘したとおり、`missing_gis_data == 0` はテーブル結合の完全性のみを示し、GBAが現地の建物を漏れなく検出できているかは未検証である。別途、現地測量データや高解像度衛星画像との突合による検証を検討する
- **30mでの観測日拡張**: 衛星データのみと同様、複数観測日が揃った時点で同じ経路での複数日比較を検討する
- **結果ドキュメントの共通様式の規約化**: 本ドキュメントで用いた台帳形式（列定義・数値の正本の置き方・標本統制の明示）を規約として定めることを別途検討する。`satellite_only_analysis_results_cellbased.md` には数値の正本の置き方と一般化可能性の限界の明示を先行して適用済みである
