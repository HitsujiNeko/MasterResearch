# 測量 GIS 7 レイヤの属性整理と地図の作成者への問い合わせ事項

**最終更新**: 2026-11-18  
**作成方法**: `src/analysis/inventory_survey_gis_attributes.py` による 7 レイヤの属性の集計（出力は `data/output/survey_gis_attribute_inventory/`）と、DH・TH・TV の代表地点の目視（研究者と Claude）による。DC・GT の問い合わせ事項は、survey_gis_data_preparation_status.md 2.7.7節の再調査（2026-11-18）を踏まえる  
**関連ドキュメント**: [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md)（整備状況・DC と GT の Level 別確認は 2.7節）, [survey_gis_dh_inventory.md](survey_gis_dh_inventory.md)・[survey_gis_th_inventory.md](survey_gis_th_inventory.md)・[survey_gis_tv_inventory.md](survey_gis_tv_inventory.md)（DH・TH・TV の Level 別確認）, [qgis_operation_guidelines.md](../02_methods/qgis_operation_guidelines.md)（図の生成手段）  
**前提知識**: 測量 GIS は CAD（DGN）由来で、何の地物かは Level（CAD の描画層の番号）から推測するしかない。座標系は EPSG:5897（VN-2000 / TM-3 zone 482）として扱っている

---

## 目的

測量 GIS（`data/gis/survey/merge_*.gpkg` の 7 レイヤ: CS・DC・DH・GT・RG・TH・TV）の属性を整理し、**分かっていること・推定（根拠つき）・分かっていないこと**を分けて記録する。そのうえで、指導教員を通じて地図の作成者に尋ねる事項を、相手が手元のデータで照合できる形（レイヤ・Level・列・値の例・図）で一覧にする。

本ドキュメントは 7 レイヤに共通する事項（方法・属性列・CS と RG・分かっていないこと・問い合わせ事項）を扱い、DH・TH・TV の Level 別の推定と目視確認はレイヤ別の文書に分けた。整理と不明点の洗い出しまでを扱う。算出コードの変更、測量 GIS を使う分析は含まない。DC・GT の Level 別の対応表と判定は [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md) 2.7節を正本とし、ここでは再掲しない。

## 1. 方法

### 1.1 属性の集計

`python -m src.analysis.inventory_survey_gis_attributes` で 7 レイヤを読み、次の表を `data/output/survey_gis_attribute_inventory/` に出力した（2026-11-16 実行）。本ドキュメントの件数・大きさは、特記がなければこの出力による。

| ファイル | 内容 |
|---|---|
| `columns.csv` | 列の一覧（定義上の型・欠損の割合・値の種類の数） |
| `geometry_types.csv` | ジオメトリ型別の件数 |
| `levels.csv` | Level 別の件数（点・線・面の内訳と、属性が入っている件数）。**全 Level の表はこの CSV を正本とする** |
| `value_distribution.csv` | `Type`・`ColorIndex`・`Weight`・`Style`・`GraphicGroup` の値の分布 |
| `style_combinations.csv` | Level × 形 × `Type`・`ColorIndex`・`Weight`・`Style` の件数 |
| `sizes_by_level.csv` | Level 別の線の長さ・面の面積（中央値・最大） |
| `attribute_examples.csv` | Level 別の `Text`・`MSLink`・`EntityNum` の値の例（多い順の上位 5 件と、乱数シード 42 で選んだ 5 件） |
| `ulink_linkages.csv` | Level 別の `ULink`（DGN のリンク情報）の種類別件数 |
| `inventory_summary.json` | レイヤ別の概要・集計条件・来歴 |

読み込みの前提は次のとおり。

- ファイルに CRS がないため EPSG:5897 を付与し、長さ・面積はこの投影座標（メートル）で計算した
- ジオメトリ型が混在するため、行ごとに判定した。「面」は Polygon と MultiPolygon、「線」は LineString と MultiLineString を合わせた数である
- `Text` には UTF-8 として読めないバイト列がある。元のバイト列を失わないよう latin-1 で読み、CSV では ASCII 以外のバイトを `\xNN` の形で残した。本ドキュメントに載せたベトナム語の読みは、TCVN3（ベトナム語の旧文字コード）として **Claude が解読したもので、未確認**である
- 座標 (500,000, 1,000,000) 付近にダミーの地物がある（DC 6・DH 3・GT 2・TH 5・TV 3 件）。図郭から大きく外れる地物（DC 1 件）、空の形（DC 649・GT 6 件）とともに、大きさの集計から除いた

照合の結果:

- 地物数は 7 レイヤとも [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md) 2.2節と一致した
- DC・GT の Level 別件数は、2.7節の値（DC の Level 5 の面 409,831 件、GT の Level 15 の線 98,297 件など）とすべて一致した
- 面積・長さの中央値も、DC の Level 28 の面以外は一致した。DC の Level 28 は、2.7節が 3.6 m²、本集計が 5.6 m² である。2.7節は空の面（面積 0。567 件）を含めて計算しており、含めると本集計でも 3.59 m² になる。ほかの Level には空の面がほとんどないため、値は変わらない

### 1.2 DH・TH・TV の目視

主な Level が集まる地点を 400 m 四方のマスの集計で選び、各レイヤ 3 地点の図を作った（確認範囲は 500 m 四方）。図は、範囲ごとに切り出して EPSG:4326 に変換したデータから、ヘッドレス PyQGIS で `src/visualization/qgis_figure.py` の `build_gis_figure` を使って描いた（[qgis_operation_guidelines.md](../02_methods/qgis_operation_guidelines.md)「図の生成手段」）。作図スクリプトはリポジトリに残していない。

各図の表示: 色付きの点・線・面 = Level（凡例を参照。同じ図の中では、同じ Level は点・線・面で同じ色）、灰色 = それ以外の Level、白い枠 = 確認範囲。背景は Esri World Imagery（出典: Esri, Maxar, Earthstar Geographics, and the GIS User Community）で、撮影時期は測量時点（2015〜2017年）より新しい。

一時的な集計（スクリプトは残していない）で、TV の Level 2 の面の重複と重なりも数えた（[survey_gis_tv_inventory.md](survey_gis_tv_inventory.md)）。TV の記号は、公開土地被覆データ・NDVI・LST と比べ、区画への割り当ても調べた（同 4・5章）。TH の水面は、公開水域データと重ねて一致を数え、採否を判定した（[survey_gis_th_inventory.md](survey_gis_th_inventory.md) 4・5章）。

## 2. 7 レイヤに共通する属性列

7 レイヤとも同じ 10 列を持つ。列の意味は GDAL の DGN ドライバが DGN の要素から取り出す項目としての意味であり、**データの作成者がどう使ったかは未確認**である。

| 列 | 定義上の型 | 意味（DGN の要素として） | 欠損の割合（CS / DC / DH / GT / RG / TH / TV） | 値の種類の数（同上） |
|---|---|---|---|---|
| `Type` | int32 | 要素の種類（3: 線分、4: 折れ線、6: 閉じた図形、11: 曲線、12: 複合線、14: 複合図形、15: 楕円、16: 円弧、17: 文字、21: B スプラインの制御点） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 7 / 9 / 7 / 9 / 6 / 8 / 9 |
| `Level` | int32 | 描画層の番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 23 / 50 / 14 / 48 / 4 / 34 / 27 |
| `GraphicGroup` | int32 | 図形グループの番号（0 はグループなし） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 20 / 1 / 1 / 1 / 2 / 184 |
| `ColorIndex` | int32 | 色番号（色表は手元にない） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 34 / 7 / 26 / 1 / 14 / 8 |
| `Weight` | int32 | 線の太さの番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 4 / 5 / 1 / 6 / 2 / 4 / 2 |
| `Style` | int32 | 線種の番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 3 / 2 / 5 / 1 / 2 / 1 |
| `EntityNum` | int32 | データベースへのリンクの表番号 | 0.842 / 0.995 / 1.000 / 0.919 / 0.996 / 0.996 / 1.000 | 1,635 / 437 / 0 / 3,418 / 2 / 49 / 14 |
| `MSLink` | int32 | データベースへのリンクの行番号 | 0.842 / 0.995 / 1.000 / 0.919 / 0.996 / 0.996 / 1.000 | 756 / 144 / 0 / 329 / 2 / 37 / 3 |
| `Text` | 文字列 | 文字要素の内容 | 0.582 / 0.961 / 0.557 / 0.983 / 0.918 / 0.992 / 1.000 | 704 / 6,190 / 1,214 / 1,393 / 41 / 163 / 3 |
| `ULink` | 文字列 | その他のリンク情報（GDAL が JSON にしたもの） | 0.792 / 0.464 / 0.391 / 0.244 / 0.128 / 0.016 / 0.940 | 2,026 / 112,215 / 5,456 / 82,919 / 345 / 3,462 / 2,588 |

- **`Text` の非 ASCII の値は、すべて UTF-8 として不正**だった（CS 2,061・DC 12,200・GT 3,064・TH 247・TV 1 件。DH・RG は ASCII のみ）。TCVN3 として読むと意味の通るベトナム語になる（例: `H\xb5 N\xe9i` → Hà Nội）
- `ULink` のリンク ID は 7 レイヤ共通で 32047（GDAL の判定は ODBC）・65・20905・31225・0 などがある。DC では 156,698 件（34%）が ODBC のリンクを持つ。リンク先のデータベースは手元にない
- `ULink` の中身を一時的な集計（2026-11-18、スクリプトは残していない）で調べた。**標高・建物の属性（階数・用途など）は入っていない**
  - 構造: 先頭の語が見出し（0x1000 の印と、続く語の数）、2 語目がリンク ID、残りが中身である。GDAL が出す `size` は（見出しの下位バイト + 1）× 2 バイトと一致する
  - ID 65（0x0041）: 5 語目が `ColorIndex` と 96〜100% 一致し、内側を持つ要素（`Type` 15 楕円・6 閉じた図形・14 複合図形）に付く。図形の内部を塗る色の指定とみられ、データベースへのリンクではない
  - ID 32047（0x7D2F）: 中身は 1 つの整数（0〜490,025）である。同じ番号を持つ地物は、DC・GT・TH では 97〜98%、DH では 81% が別々の図葉にあり、図葉（DGN ファイル）ごとの通し番号のように振る舞う。データベースのキーか、要素どうしを結ぶ番号かは分からない。`MSLink` とは一致しない（両方を持つ 12,968 件のうち一致は 1 件）
  - ID 0: ほぼすべての語が 0 で、中身がない
  - そのほか（20905・31225・24162・32980・90・22247・20223・21436）: 意味は分からない。21436（GT の 1 件）は中身に ASCII の文字列「Round」を含む
- `EntityNum`・`MSLink` はほとんどが欠損で、値があるのは CS 16%・GT 8% など一部に限られる
- 線の太さ・線種・色は、DC・GT では Level と組み合わせて意味を持つ場合がある（例: DC の Level 5 の面は色 10・太さ 1。2.7.2節）。全組み合わせは `style_combinations.csv` を参照する

## 4. 分かっていること／推定／分かっていないこと

「分かっていること」は、データの集計や地図履歴書から確かめた事実、または研究者が判定したものに限る。

| 対象 | 分かっていること | 推定（根拠） | 分かっていないこと |
|---|---|---|---|
| 全レイヤの列 | 10 列は DGN の要素の項目である。`Level` に欠損はない | — | 作成者が `GraphicGroup`・`ColorIndex`・`Weight`・`Style` をどう使い分けたか。色表 |
| 全レイヤの `Text` | 非 ASCII の値は UTF-8 として不正である | TCVN3 で書かれている（解読すると意味の通るベトナム語になる） | 文字コード |
| `EntityNum`・`MSLink`・`ULink` | DC の 34% などが ODBC のリンクを持つ。`ULink` の中身に標高・建物の属性はない（2章） | 外部のデータベースと結び付けて作られた。ID 65 は塗りの色の指定、ID 32047 は図葉ごとの通し番号 | リンク先のデータベースがあるか、その内容（建物の階数・用途など）。ID 32047 の番号が何を指すか |
| 座標系 | ファイルに CRS がない。CS の欄外の注記は「国家座標系 VN-2000」「国家高さ基準 Hòn Dấu」とする | EPSG:5897（TM-3 zone 482）。重ね合わせで位置が合う（survey_gis_data_preparation_status.md 2.3節） | 投影帯・中央子午線 |
| 時点 | 撮影は 2015年10月〜2016年5月、現地調査・図化は 2017年（地図履歴書） | 欄外の「2017年まで修正」は図化の時点を指す。GBA の建物面積の 18% が DC の面の外にあり、DC にない新しい住宅地がある（2.7.7節） | 2017年より後の修正の有無 |
| 図葉のそろい方 | DC の 251-c は含まれる（2.6節） | — | DC の全 80 図葉、TV の 11-c がそろっているか |
| Level のコード表 | 手元にない（2.7.1節） | — | 全レイヤの Level の定義 |
| CS | Level 5 が図郭内枠、Level 7 が図郭外枠（2.5節） | 2・3・4・9 は図葉番号、16・17 は座標の目盛り、19・20・32・33 は欄外の注記、23・24・46 は行政区域名 | Level 6 などの線の意味 |
| RG | Level 7 が区、Level 10 が坊の境界（2.5節） | 注記の「Q」「P」は区・坊 | 注記の番号の意味。Level 5・20 |
| DC | Level 5 の面が建物の外形（2.7節。研究者判定）。GBA の建物面積のうち、施設などほかの Level の面の中にあるのは 3.7%（2.7.7節） | Level 5 以外の面は施設の敷地と記号（2.7節）。Level 5 の `Text` の数字は建物の高さか屋上の標高（GBA の高さと順位相関 0.71、地盤を引くと 19〜78 m。2.7.7節） | 数字が高さか標高か、どの建物に付けるか。施設の Level で描かれた建物はどれか |

## 5. 地図の作成者への問い合わせ事項

優先度は、付録の測量建物置き換え（DC の建物を使う）と、研究者が採用を検討している DH の標高点、道路面積率の候補として採否を保留した GT の面に効くものを「研究に効く」、そのほかの採否が未決のレイヤや、データの理解を助けるものを「あると助かる」とした。不採用と判定したレイヤ（TH）の Level の意味は尋ねない（使わないデータについて相手に手間をかけないため）。リンク先のデータベース（B-9）は、`ULink` に属性そのものが入っていないと分かり（2章）、あっても階数などを含む見込みが小さいため「あると助かる」とした。施設の Level で描かれた建物（B-3）は、公開建物データ（GBA）の建物面積の 3.7% と少ないため「あると助かる」とし、GT の面（A-4）は道路面積率に使える見込みがあるため「研究に効く」とした（survey_gis_data_preparation_status.md 2.7.7節）。図の番号は、DH・TV の各文書の 3章（[DH](survey_gis_dh_inventory.md)・[TV](survey_gis_tv_inventory.md)）と survey_gis_data_preparation_status.md 2.7.6節・2.7.7節（DC・GT）の図を指す。
