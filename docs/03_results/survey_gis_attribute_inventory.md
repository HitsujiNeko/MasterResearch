# 測量 GIS 7 レイヤの属性整理と地図の作成者への問い合わせ事項

**最終更新**: 2026-11-19  
**作成方法**: `src/analysis/inventory_survey_gis_attributes.py` による 7 レイヤの属性の集計（出力は `data/output/survey_gis_attribute_inventory/`）と、DH・TH・TV の代表地点の目視（研究者と Claude）による。DC・GT の問い合わせ事項は、DC・GT の文書の再調査（2026-11-18）を踏まえる。地図履歴書（80 件）の記載は本文を取り出して比べた（4.1節）  
**関連ドキュメント**: [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md)（整備状況）, [survey_gis_dc_inventory.md](survey_gis_dc_inventory.md)・[survey_gis_gt_inventory.md](survey_gis_gt_inventory.md)（DC・GT の Level 別確認）, [survey_gis_dh_inventory.md](survey_gis_dh_inventory.md)・[survey_gis_th_inventory.md](survey_gis_th_inventory.md)・[survey_gis_tv_inventory.md](survey_gis_tv_inventory.md)（DH・TH・TV の Level 別確認）, [qgis_operation_guidelines.md](../02_methods/qgis_operation_guidelines.md)（図の生成手段）  
**節番号の表記**: 「整備状況 2.7節」などは [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md) の節を、文書名のない「4.1節」などは本ドキュメントの節を指す  
**前提知識**: 測量 GIS は CAD（DGN）由来で、何の地物かは Level（CAD の描画層の番号）から推測するしかない。座標系は EPSG:5897（VN-2000 / TM-3 zone 482）として扱っている

---

## 目的

測量 GIS（`data/gis/survey/merge_*.gpkg` の 7 レイヤ: CS・DC・DH・GT・RG・TH・TV）の属性を整理し、**分かっていること・推定（根拠つき）・分かっていないこと**を分けて記録する。そのうえで、指導教員を通じて地図の作成者に尋ねる事項を、相手が手元のデータで照合できる形（レイヤ・Level・列・値の例・図）で一覧にする。

本ドキュメントは 7 レイヤに共通する事項（方法・属性列・CS と RG・分かっていないこと・問い合わせ事項）を扱い、DC・GT・DH・TH・TV の Level 別の推定と目視確認はレイヤ別の文書に分けた。整理と不明点の洗い出しまでを扱う。算出コードの変更、測量 GIS を使う分析は含まない。DC・GT の Level 別の対応表と判定は [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md) 2.7節を正本とし、ここでは再掲しない。

## 1. 方法

### 1.1 属性の集計

`python -m src.analysis.inventory_survey_gis_attributes` で 7 レイヤを読み、次の表を `data/output/survey_gis_attribute_inventory/` に出力した（2026-11-16 実行、スクリプトの修正後に 2026-11-19 再実行。CSV の値は変わっていない）。本ドキュメントの件数・大きさは、特記がなければこの出力による。

| ファイル | 内容 |
|---|---|
| `columns.csv` | 列の一覧（定義上の型・欠損の割合・値の種類の数） |
| `geometry_types.csv` | ジオメトリ型別の件数 |
| `levels.csv` | Level 別の件数（点・線・面の内訳と、属性が入っている件数）。**全 Level の表はこの CSV を正本とする** |
| `value_distribution.csv` | `Type`・`ColorIndex`・`Weight`・`Style`・`GraphicGroup` の値の分布 |
| `style_combinations.csv` | Level × 形 × `Type`・`ColorIndex`・`Weight`・`Style` の件数 |
| `sizes_by_level.csv` | Level 別の線の長さ・面の面積（中央値・最大） |
| `attribute_examples.csv` | Level 別の `Text`・`MSLink`・`EntityNum` の値の例（多い順の上位 5 件と、乱数シード 42 で選んだ 5 件） |
| `ulink_linkages.csv` | Level 別の `ULink`（DGN のリンク情報）の種類別件数 |
| `inventory_summary.json` | レイヤ別の概要・集計条件・来歴 |

読み込みの前提は次のとおり。

- ファイルに CRS がないため EPSG:5897 を付与し、長さ・面積はこの投影座標（メートル）で計算した
- ジオメトリ型が混在するため、行ごとに判定した。「面」は Polygon と MultiPolygon、「線」は LineString と MultiLineString を合わせた数である
- `Text` には UTF-8 として読めないバイト列がある。元のバイト列を失わないよう latin-1 で読み、CSV では ASCII 以外のバイトを `\xNN` の形で残した。本ドキュメントに載せたベトナム語の読みは、TCVN3（ベトナム語の旧文字コード）として **Claude が解読したもので、未確認**である
- 座標 (500,000, 1,000,000) 付近にダミーの地物がある（DC 6・DH 3・GT 2・TH 5・TV 3 件）。図郭から大きく外れる地物（DC 1 件）、空の形（DC 649・GT 6 件）とともに、大きさの集計から除いた

照合の結果:

- 地物数は 7 レイヤとも [survey_gis_data_preparation_status.md](survey_gis_data_preparation_status.md) 2.2節と一致した
- DC・GT の Level 別件数は、DC・GT の文書（各 2章）の値（DC の Level 5 の面 409,831 件、GT の Level 15 の線 98,297 件など）とすべて一致した
- 面積・長さの中央値も、DC の Level 28 の面以外は一致した。DC の Level 28 は、DC の文書が 3.6 m²、本集計が 5.6 m² である。整備状況 2.7節は空の面（面積 0。567 件）を含めて計算しており、含めると本集計でも 3.59 m² になる。ほかの Level には空の面がほとんどないため、値は変わらない

### 1.2 DH・TH・TV の目視

主な Level が集まる地点を 400 m 四方のマスの集計で選び、各レイヤ 3 地点の図を作った（確認範囲は 500 m 四方）。図は、範囲ごとに切り出して EPSG:4326 に変換したデータから、ヘッドレス PyQGIS で `src/visualization/qgis_figure.py` の `build_gis_figure` を使って描いた（[qgis_figure_generation.md](../02_methods/qgis_figure_generation.md)「図の生成手段」）。作図スクリプトはリポジトリに残していない。

各図の表示: 色付きの点・線・面 = Level（凡例を参照。同じ図の中では、同じ Level は点・線・面で同じ色）、灰色 = それ以外の Level、白い枠 = 確認範囲。背景は Esri World Imagery（出典: Esri, Maxar, Earthstar Geographics, and the GIS User Community）で、撮影時期は測量時点（2015〜2017年）より新しい。

一時的な集計（スクリプトは残していない）で、TV の Level 2 の面の重複と重なりも数えた（[survey_gis_tv_inventory.md](survey_gis_tv_inventory.md)）。TV の記号は、公開土地被覆データ・NDVI・LST と比べ、区画への割り当ても調べた（同 4・5章）。TH の水面は、公開水域データと重ねて一致を数え、採否を判定した（[survey_gis_th_inventory.md](survey_gis_th_inventory.md) 4・5章）。

## 2. 7 レイヤに共通する属性列

7 レイヤとも同じ 10 列を持つ。列の意味は GDAL の DGN ドライバが DGN の要素から取り出す項目としての意味であり、**データの作成者がどう使ったかは未確認**である。

| 列 | 定義上の型 | 意味（DGN の要素として） | 欠損の割合（CS / DC / DH / GT / RG / TH / TV） | 値の種類の数（同上） |
|---|---|---|---|---|
| `Type` | int32 | 要素の種類（3: 線分、4: 折れ線、6: 閉じた図形、11: 曲線、12: 複合線、14: 複合図形、15: 楕円、16: 円弧、17: 文字、21: B スプラインの制御点） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 7 / 9 / 7 / 9 / 6 / 8 / 9 |
| `Level` | int32 | 描画層の番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 23 / 50 / 14 / 48 / 4 / 34 / 27 |
| `GraphicGroup` | int32 | 図形グループの番号（0 はグループなし） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 20 / 1 / 1 / 1 / 2 / 184 |
| `ColorIndex` | int32 | 色番号（色表は手元にない） | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 34 / 7 / 26 / 1 / 14 / 8 |
| `Weight` | int32 | 線の太さの番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 4 / 5 / 1 / 6 / 2 / 4 / 2 |
| `Style` | int32 | 線種の番号 | 0 / 0 / 0 / 0 / 0 / 0 / 0 | 1 / 3 / 2 / 5 / 1 / 2 / 1 |
| `EntityNum` | int32 | データベースへのリンクの表番号 | 0.842 / 0.995 / 1.000 / 0.919 / 0.996 / 0.996 / 1.000 | 1,635 / 437 / 0 / 3,418 / 2 / 49 / 14 |
| `MSLink` | int32 | データベースへのリンクの行番号 | 0.842 / 0.995 / 1.000 / 0.919 / 0.996 / 0.996 / 1.000 | 756 / 144 / 0 / 329 / 2 / 37 / 3 |
| `Text` | 文字列 | 文字要素の内容 | 0.582 / 0.961 / 0.557 / 0.983 / 0.918 / 0.992 / 1.000 | 704 / 6,190 / 1,214 / 1,393 / 41 / 163 / 3 |
| `ULink` | 文字列 | その他のリンク情報（GDAL が JSON にしたもの） | 0.792 / 0.464 / 0.391 / 0.244 / 0.128 / 0.016 / 0.940 | 2,026 / 112,215 / 5,456 / 82,919 / 345 / 3,462 / 2,588 |

- **`Text` の非 ASCII の値は、すべて UTF-8 として不正**だった（CS 2,061・DC 12,200・GT 3,064・TH 247・TV 1 件。DH・RG は ASCII のみ）。TCVN3 として読むと意味の通るベトナム語になる（例: `H\xb5 N\xe9i` → Hà Nội）
- `ULink` のリンク ID には 32047（GDAL の判定は ODBC）・65・20905・31225・0 などがある。32047・65・20905・0 は 7 レイヤすべてにあり、31225 は CS にない（レイヤ別の内訳は `ulink_linkages.csv`）。DC では 156,698 件（34%）が ODBC のリンクを持つ。リンク先のデータベースは手元にない
- `ULink` の中身を一時的な集計（2026-11-18、スクリプトは残していない）で調べた。**標高・建物の属性（階数・用途など）は入っていない**
  - 構造: 先頭の語が見出し（0x1000 の印と、続く語の数）、2 語目がリンク ID、残りが中身である。GDAL が出す `size` は（見出しの下位バイト + 1）× 2 バイトと一致する
  - ID 65（0x0041）: 5 語目が `ColorIndex` と 96〜100% 一致し、内側を持つ要素（`Type` 15 楕円・6 閉じた図形・14 複合図形）に付く。図形の内部を塗る色の指定とみられ、データベースへのリンクではない
  - ID 32047（0x7D2F）: 中身は 1 つの整数（0〜490,025）である。同じ番号を持つ地物は、DC・GT・TH では 97〜98%、DH では 81% が別々の図葉にあり、図葉（DGN ファイル）ごとの通し番号のように振る舞う。データベースのキーか、要素どうしを結ぶ番号かは分からない。`MSLink` とは一致しない（両方を持つ 12,968 件のうち一致は 1 件）
  - ID 0: ほぼすべての語が 0 で、中身がない
  - そのほか（20905・31225・24162・32980・90・22247・20223・21436）: 意味は分からない。21436（GT の 1 件）は中身に ASCII の文字列「Round」を含む
- `EntityNum`・`MSLink` はほとんどが欠損で、値があるのは CS 16%・GT 8% など一部に限られる
- 線の太さ・線種・色は、DC・GT では Level と組み合わせて意味を持つ場合がある（例: DC の Level 5 の面は色 10・太さ 1。[DC の確認](survey_gis_dc_inventory.md) 2章）。全組み合わせは `style_combinations.csv` を参照する

## 4. 分かっていること／推定／分かっていないこと

「分かっていること」は、データの集計や地図履歴書から確かめた事実、または研究者が判定したものに限る。

### 4.1 地図履歴書（80 件）の記載

| 項目 | 記載 | 図葉による違い |

| 縮尺 | 1:2,000 | なし |

| 高さの基準 | 国家高さ基準（Hòn Dấu、ハイフォン市） | なし |
| 空中写真 | Rollei AIC Pro 45、飛行高度 850 m、地上解像度 0.03 m | 撮影は 2015年10月が 30 件、2016年5月が 49 件、「2016年」のみが 1 件。色は 72 件が R・G・B・近赤外、8 件（10・11・12 番台）が R・G・B |

### 4.2 一覧

| 対象 | 分かっていること | 推定（根拠） | 分かっていないこと |
|---|---|---|---|

## 5. 地図の作成者への問い合わせ事項

地図履歴書（4.1節）は、作成時に適用した規程として「Phụ lục 1（現地調査用の地物の分類表）」「Phụ lục 3（地物の分類）」「Phụ lục 5a（地形図の内容と記号）」「Phụ lục 5b（数値地形図の編集内容。付録 B・C）」「Thông tư 55/2014/TT-BTNMT（1:2,000・1:5,000 基盤地理データベースの構造・内容）」などを挙げる（10・11・12 番台の 8 件は Phụ lục を挙げない）。Level・色・線種・注記の割り当てはこれらの規程で決まっているとみられる（未確認）。そこで、**まず割り当て表（5.1節）を 1 つお願いし、それがあれば答えが出る質問（5.2節）は、表がない場合に限って個別に尋ねる**形にした。割り当て表とは関係のない質問は 5.3節にまとめた。座標系・高さの基準・標高点の精度・等高線の間隔は地図履歴書に書かれていたため、尋ねない（4.1節）。

優先度は、付録の測量建物置き換え（DC の建物を使う）と、研究者が採用を検討している DH の標高点、採否を保留した GT の面（道路面積率）と TV の区画（緑地の面積率）に効くものを「研究に効く」、データの理解を助けるものを「あると助かる」とした。不採用と判定したレイヤ（TH）と、使わない GT の線の Level の意味は尋ねない（使わないデータについて相手に手間をかけないため）。施設の Level で描かれた建物（2-4）は、公開建物データ（GBA）の建物面積の 3.7% と少ないため「あると助かる」とした（[DC の確認](survey_gis_dc_inventory.md) 4.2節）。リンク先のデータベース（3-8）は、`ULink` に属性そのものが入っていないと分かり（2章）、あっても階数などを含む見込みが小さいため「あると助かる」とした。図の番号は、DH・TV の各文書の 3章（[DH](survey_gis_dh_inventory.md)・[TV](survey_gis_tv_inventory.md)）と DC・GT の各文書の目視確認の記録（[DC の確認](survey_gis_dc_inventory.md) 6章・[GT の確認](survey_gis_gt_inventory.md) 5章）の図を指す。
