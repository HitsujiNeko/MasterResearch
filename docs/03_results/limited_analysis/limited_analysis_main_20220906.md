## 8. 主採用の観測（2022-09-06）の結果

**本章が衛星＋公開GISデータのシナリオの主結果である。** 主採用の観測 032358 で、採用構成（ラン13 相当: 変数セット `both`・建物高さ `mean`・水指数 `none`・GLC・WorldPop2020）を30mで実行した。観測を変えた理由は [observation_selection.md](../../02_methods/observation_selection.md) 8章を正本とする。

### 8.1 実行内容と数値の正本

- **出力先**: `data/output/limited/20220906_032358/`（接頭辞 `dataset_limited_20220906_032358_hanoi_30m_both_bh_mean_wi_none`）。数値の正本は1.1節と同じ種別のファイルである
- **データセット**: 現行の手順（新世代: ROI でクリップ済み・MNDWI あり・1.4節）で作った。列構成は 032305 の新世代データセットと同一である
- **処理条件**: フィルタ条件・サンプリング・モデル設定は3章と同じである（`IN_ANALYSIS_AREA == 1` のみ・`LST_VALID_RATIO >= 0.5`・10万件・乱数シード42・RF 300本・ブロック 2,700m・5分割）。分散0の列 `LULC_BARE_COV` は 032305 と同じく除外された
- **来歴**: `results.json` の `provenance.git.dirty` は `false` である。生成後に共通評価セルの機能（8.6節）を加えて共通モジュールと分析スクリプトを変えたため、陳腐化チェック（`scripts/check_result_staleness.py`）では「要再実行（コード変更）」と判定される。ただし、引数を指定しない場合の挙動は変えていないため、**上の出力先にある追跡対象の結果は再生成していない**。衛星＋公開GISデータでは、診断ラン（`--diagnose-only`）で母数とフィルタ脱落が一致することを確かめ、標本の一致はテストで確かめた。同じ変更を受けた衛星データのみでは、既定の引数で出力先だけを一時ディレクトリに変えて再実行し、その一時出力の標本の `cell_id` と Spatial CV の fold 別指標が追跡対象の結果と完全に一致した（[satellite_only_analysis_results_cellbased.md](../satellite_only_analysis_results_cellbased.md) 7.1節）

生成コマンド（データセットは `.gitignore` 対象・再生成可能）:

```bash
python -m src.analysis.urban_params --city hanoi --lst-file data/satellite/lst/2022/LST_Landsat8_20220906_032358Z.tif --satellite-file data/satellite/indices/2022/INDICES_Landsat8_20220906_032358Z.tif --scales 30
python -m src.analysis.build_dataset --city hanoi --scale 30 --scenario limited --tables idx_20220906_032358 lst_20220906_032358 --name limited_20220906_032358
python -m src.analysis.analysis_rq3_limited --dataset-path data/output/datasets/dataset_limited_20220906_032358_hanoi_30m.gpkg --output-dir data/output/limited/20220906_032358 --scale 30 --random-state 42 --sample-size 100000 --block-size-m 2700 --cv-splits 5 --rf-trees 300 --variable-set both --building-height mean --population-source worldpop2020 --water-index none
```

`--dataset-path`・`--output-dir` を省略した場合の既定値も 032358 を指すが、再現時は上のとおりすべて明示する。

### 8.5 旧採用（ラン13）との比較

同じ構成（採用構成）を雨季の2観測で比べる。比較相手は 032305 の新世代の採用構成であるラン13（[observation_selection.md](../../02_methods/observation_selection.md) 9.1節の「新世代のランに限る」による）。

**比較相手の妥当性**: ラン13の `results.json` は `provenance.git.dirty` が真で記録されており（実行時に未コミットと表示されたのは改行コードだけが異なるファイルで、内容の差分は無かった・3.7節）、生成後にコードも変わったため、陳腐化チェックでは「要再実行（コード変更）」と判定される。ただし、クリーンなコミットで生成した全域ラン（`data/output/limited/20230707_032305_area_comparison/` の `..._both_bh_mean_wi_none_results.json`・[survey_area_comparison_results.md](../survey_area_comparison_results.md)）とは、ランダム分割・Spatial CV の R²・RMSE・MAE、母数のファネル、SHAP 平均絶対値がすべて一致する。数値は現行のコードで再現できているため、比較相手として使う。

**比べる量と比べない量**: 観測が違うと LST の分布が違うため、LST の絶対値と RMSE・MAE（°C）は比べない（[observation_selection.md](../../02_methods/observation_selection.md) 8.5節）。R²、RMSE を各観測の LST の標準偏差で割った値、変数重要度の順位を比べる。**SHAP 平均絶対値は LST と同じ単位（°C）を持つため、値の大きさを比べるときは各観測の LST の標準偏差で割る。**

| 指標 | 032358（本章） | 032305（ラン13） | 差 |
|---|---|---|---|
| RF R²（Spatial CV） | 0.8392 | 0.7531 | **+0.0862** |
| Linear R²（Spatial CV） | 0.7652 | 0.6439 | **+0.1213** |
| RF R²（ランダム分割） | 0.8569 | 0.7995 | +0.0574 |
| Linear R²（ランダム分割） | 0.7660 | 0.6536 | +0.1124 |
| RF の RMSE ÷ LST の標準偏差（Spatial CV） | 0.398 | 0.495 | −0.097 |
| Linear の RMSE ÷ LST の標準偏差（Spatial CV） | 0.481 | 0.595 | −0.113 |
| SHAP 上位4位 | `NDBI`・`LULC_BUILT_COV`・`POP_DEN_WORLDPOP2020`・`ELEV_MEAN` | 同じ順位 | 順位は不変 |
| SHAP `NDBI` ÷ LST の標準偏差 | 0.388 | 0.295 | +0.093 |
| Permutation 上位2位 | `NDBI`・`ELEV_MEAN` | 同じ順位 | 順位は不変 |

**差の読み方**（物差しは2.1節「標本変動の実測」。母集団自体が異なるため、そこで測った変動は下限として扱う）:

- **R² の差（+0.06〜+0.12）は、標本変動（0.003程度）をはるかに超える。** RF と線形の差（Spatial CV）は 0.1092 → 0.0740 に縮み、線形モデルの改善のほうが大きい
- **SHAP 上位4位の順位は変わらない。** 第5・6位（`NDVI`・`NTL_MEAN`）も同じだが、一致していることには重みを置かない。2.1節では第5・6位（`ndwi` 構成の `NDVI`・`NDWI`）が標本の入れ替わりだけで入れ替わった。構成の異なる本章へこの測定を当てはめるのは外挿だが、第5位以下の順位は標本で動きうるものとして扱う。`NDBI` の SHAP を各観測の LST の標準偏差で割った値は +0.093 と、SHAP の変動幅（2.1節の 0.1程度をラン1 の母集団の標準偏差 2.50°C で割って 0.04程度）を超えて大きくなった
- **Permutation の第3〜5位（`LULC_BUILT_COV`・`NDVI`・`POP_DEN_WORLDPOP2020`）は順位が入れ替わった。** 032305 では3変数の値が 0.130〜0.145 に、032358 では 0.068〜0.090 に固まっており、差が小さいため順位として読まない
- 032305 で SHAP 第7位だった `LULC_WATER_COV` は、LST の標準偏差で割った値で 0.033 → 0.009（第9位）に下がった。第7位以下は値が小さく、変動の物差しを測っていないため、この差を解釈しない

**R² が上がった理由は切り分けていない。** 次の2つが重なっており、本章の比較では分離できない。

- **母集団の違い**: 最終母数が 171,894セル増え（8.2節）、脱落が空間的に集中していたブロックが無くなった。032305 で欠けていたセルの性格によって、説明しやすさそのものが変わりうる
- **観測条件の違い**: 都心と郊外の LST 差は 032358 で +2.94°C（標準偏差比 1.10）、032305 で +2.02°C（同 0.79）であり（[observation_selection.md](../../02_methods/observation_selection.md) 8.4節）、都市構造との関係が強く出やすい観測である可能性がある（**推定**）。同ドキュメント8.5節のとおり、この差を主採用の根拠に使うことは循環的な選び方に間接的に近づくため、**「主採用の観測では R² が高い」ことを手法の性能の向上として読まない**

切り分けには、2観測に共通するセルへ限定した評価が要る（7節）。

乾季の比較用の観測 `2024-11-30T03:23:36` を加えた3観測の比較は [observation_comparison_results.md](../observation_comparison_results.md) にある。

### 8.6 衛星データのみとの比較（共通評価セル）

衛星データのみも同じ観測 032358 で実行した（[satellite_only_analysis_results_cellbased.md](../satellite_only_analysis_results_cellbased.md) 7章）。各シナリオを既定のまま実行すると母数が 45,321セル食い違い、10万件の標本は事実上別物になる（2.1節）。そこで、**両シナリオに共通するセルから評価セルと fold 割り当てを1つに固定し、同じセル・同じ分割で評価した**。定義・生成手順・区間の求め方は [analysis_workflow.md](../../02_methods/analysis_workflow.md) 5.3.3節を正本とする。

#### 8.6.1 評価の設計と数値の正本

- **共通集合**: 衛星データのみと衛星＋公開GISデータ（人口ソース3版それぞれ）の有効母集団の積とした。人口3版を含めたのは、あとから人口ソース間の比較にも同じ評価セルを使えるようにするためである（今回は行っていない）
- **評価セル**: 共通集合から10万件を抽出し（乱数シード42）、2,700m ブロック・GroupKFold 5分割で fold を割り当てた。非空ブロック数は 502、fold ごとのテスト行数は 19,999〜20,001 である
- **モデル構成**: 衛星データのみは分光指数3変数（`NDVI`・`NDBI`・`NDWI`）、衛星＋公開GISデータは採用構成（14変数。`LULC_BARE_COV` は分散0で除外）。その他の条件（RF 300本など）は8.1節と同じである
- **差の向き**: すべて **衛星＋公開GISデータ − 衛星データのみ** とする。R² は正、RMSE・MAE は負なら衛星＋公開GISデータが良い
- **数値の正本**

いずれも `provenance.git.dirty` は `false` で記録されている。生成コマンドは [analysis_workflow.md](../../02_methods/analysis_workflow.md) 5.3.3節のとおりである（表の1〜4行目は引数がすべて既定値。5行目の感度分析の引数は同節。`ndwi` − 採用構成の差は、保存済みの反復・単発の比較の結果から `compare_water_index_variants.py` で求めた）。20シードの反復は1シードあたり約13分（2シナリオの Spatial CV）かかった。

**2026-11-01 に、評価セルと比較・反復の検証・来歴を強化した後のコードで、上の表の1〜4行目（全工程ランは2シナリオ分で、結果 JSON は計5件）をすべて再生成した（5行目の感度分析は 2026-11-18 の生成）。**数値は再生成前と一致した。評価セル・両シナリオの全工程ラン（標本・fold 別指標・特徴量重要度・SHAP 重要度・相関）・単発の比較・反復のシードごとの fold 別指標は完全一致である。反復の集計値（差の平均・sd・区間・パーセンタイル）だけは最大 4.2e-16 ずれた。途中で中断したため13シードを途中結果の CSV から読み直しており、CSV の読み込みの丸め（最下位ビット）が残ったためである。本節の表の値（小数第3〜4位）には影響しない。SHAP の summary 図・dependence 図は描画の乱数（点の順序・ジッター）によりバイト単位では一致しないが、SHAP 値は一致している。

5行目のうち `ndwi` − 採用構成の差のファイル（`water_index_comparison_` で始まる3件）は、2026-11-20 に保存済みの反復・単発の比較の結果から生成した。それまで8.6.6節の表に記していた値（一時的な集計で求めたもの）とは、小数第4位まですべて一致した。

**共通評価セルの全工程ランは、8.3節の主結果とは別の標本による。** 衛星＋公開GISデータの単独の性能は8.3節を主結果とし、本節の数値はシナリオ間の比較にだけ使う。

#### 8.6.5 読み方と限界

- **同じセル・同じ分割の上で、衛星＋公開GISデータは衛星データのみを Spatial CV の RF R² で約 +0.086、線形 R² で約 +0.073 上回る。** 差は分割の違い・標本の違いのいずれでも説明できない大きさである。RMSE では RF で約 0.25°C、線形で約 0.19°C 小さい
- **この差には分光指数の構成の違いも含まれる。** 分光指数の扱いはシナリオ間で異なる（衛星データのみは `NDWI` を含む3変数、衛星＋公開GISデータは `NDWI` を除外・6.5節）。差は「衛星＋公開GISデータの採用構成の変数集合」と「衛星データのみの3変数」の比較であり、公開GIS由来の変数だけの寄与を切り出したものではない。ただし、水域を表す変数として `LULC_WATER_COV` を用い `NDWI` を除外したことも、公開GISを加えた効果の一部と読む（8.6.6節）。分光指数を揃えた感度分析（8.6.6節）では差はほとんど変わらず、RF ではわずかに大きくなった。主結果は採用構成どうしの比較のままとする
- **Spatial CV の値は同一ROI内・空間的に近い場所への内挿性能である**（8.3節）。差も内挿性能の差として読む
- **補正 t 区間は、R パッケージ correctR の `resampled_ttest`・`repkfold_ttest` と統計量・p 値が一致することをテストで確認し、補正係数は原典の本文と照合した**（Bouckaert & Frank (2004) は著者版、Nadeau & Bengio は同名の会議版。2003 年の雑誌版は未確認）。単発の k-fold 用の `kfold_ttest` は参照に使っていない。反復数の引数 n を J とすると、コードの係数が同パッケージの説明文と異なるためで（k = n = 5 で 0.5 と 0.45）、本研究の係数は原典と説明文に一致する。fold ごとの行数の比の平均を ρ に使う点と、反復の自由度 `J − 1` は原典に記述がない本研究の扱いである（[analysis_workflow.md](../../02_methods/analysis_workflow.md) 5.3.3節）
- **以前の参考比較との関係**: 共通評価セルを使う前の参考比較（母数・標本が別物）では、Spatial CV の差は RF +0.0917・線形 +0.0797 だった。共通評価セルでの差（RF +0.0871・線形 +0.0727）はこれよりやや小さいが、以前の比較は母集団の違いを含んでおり、標本変動（2.1節。独立な2標本で 0.01 程度）の範囲を大きく超える違いではない
- **032305 では正式な比較を行っていない。** 6.7節は参考比較のまま残す

#### 8.6.6 分光指数を揃えた感度分析

8.6.3〜8.6.5節の差には、分光指数の構成の違い（衛星データのみは `NDVI`・`NDBI`・`NDWI` の3変数、衛星＋公開GISデータの採用構成は `NDWI` を除外・6.5節）も含まれる。そこで、衛星＋公開GISデータを `NDWI` を含む構成（水指数 `ndwi`・15変数。ラン12相当）で同じ評価セル・同じ分割で実行し、衛星データのみと比べた。都心部（測量GIS範囲）でも同じ比較を行った（[survey_area_comparison_results.md](../survey_area_comparison_results.md) 7.6.5節）。

**主結果の扱い**: 主結果は採用構成どうしの比較（8.6.3〜8.6.5節）のままとし、本節は感度分析として併記する。理由は次のとおりである。

- 衛星＋公開GISデータでは、水域を表す変数として `LULC_WATER_COV` を用い、`NDWI` を除外した。水指数の構成比較（6.5節）で、`NDWI` を外すと失われる成分が恒等式から「緑/赤の比」として表せることを確かめ、水域は `LULC_WATER_COV` で表すことにして、除外による性能低下を許容した判断である。この成分が水域の情報を含まないかは検証していない（6.5.4節）。両変数の情報の代替関係（`LULC_WATER_COV` が `NDWI` の情報を代わりに担うか）は検証していない。この判断で `NDWI` を除外できたこと自体を、公開GISデータを加えた効果の一部として読む
- 下のとおり、分光指数を揃えても差はほとんど変わらず、RF では揃えたほうがわずかに大きい。主結果の差は、公開GISを加えた効果を大きく見せる方向には偏っていない。感度分析が示すのはこの性能差の小ささである

**衛星データのみを2変数（`NDVI`・`NDBI`）に揃える比較は行わない。** 理由は3つある。分光指数3変数から `NDWI` だけを外した構成を基準に使う先行例が見当たらない。衛星データのみでは `NDVI`・`NDWI` の係数・寄与を元々個別に読まない（6.7節・[satellite_only_analysis_results_cellbased.md](../satellite_only_analysis_results_cellbased.md) 5.3節）。衛星データのみには水域の情報を代わりに担う変数が無く、`NDWI` を外す実務上の理由が無い。

### 8.7 水域率の元データを JRC に差し替えた感度分析

`LULC_WATER_COV` の値は元データの選び方に敏感である。水域の面積はデータと定義によって GLC の 0.24〜2.08 倍まで変わる（[gis_data_water.md](../../01_planning/gis_data/gis_data_water.md) 7章）。同7.7節の方針では、元データは GLC_FCS30D のまま継続し、水域率を JRC Global Surface Water（以下 JRC）に差し替えた感度分析を加えることにした。本節はその結果である。**どの水域データも真値ではない。そのため、性能の優劣ではなく、結論（性能・変数の寄与の順位・水域の係数の符号）が元データを変えても保たれるかを見る。**

#### 8.7.1 方法と数値の正本

- **差し替えた候補**: 次の3つである。どれも [gis_data_water.md](../../01_planning/gis_data/gis_data_water.md) 7.1節と同じ定義・同じ集約関数・同じ正準グリッドで、30m セルの水域面積率にした。有効画素率が 0.5 未満のセルは欠測とした
  - **JRC 月次 2021-09**（`water` が 2 の画素）。JRC の収録は2021年までである。観測日（2022-09-06）とは暦月がそろうが、年は1年ずれる
  - **JRC Occurrence 50% 以上**。Occurrence の主とする閾値
  - **JRC Occurrence 25% 以上**。閾値の感度として加えた
- **差し替える列**: `LULC_WATER_COV` だけを差し替えた。**他の土地被覆6列は、次の2通りで作った（研究者判断、2026-11-26）**
  - **据え置き（主）**: 6列は GLC のまま残す。差し替えの影響を水域の列だけに限れる。その代わり、水域と他のクラスを二重に数えるセルができる（8.7.2節）
  - **正規化（副）**: 6列を互いの比を保ったまま伸縮し、和を「1 − 水域率」に戻す。GLC で6列の和が0のセル（GLC では全面が水域）は、残りをすべて参照クラスの農地に回す
- **共通セル**: GLC と JRC の3候補がすべて有効なセルに限った（8.7.3節）。共通セルの外では、派生データセットの水域の列を欠測にした。こうして、6つの版の有効母集団をそろえた
- **人口の補完**: WorldPop の水域セルの0補完（`LULC_WATER_COV >= 0.9` で判定）は、GLC による判定のまま据え置いた（研究者判断、2026-11-26）。差し替えの影響を水域の列に限るためである。JRC で判定し直した場合との食い違いは 8.7.2節に記録した
- **実行**: 6つの版（3候補 × 据え置き・正規化）と GLC 版を、8.1節と同じ設定で実行した。共通評価セル（`--evaluation-cells`）も加え、すべての版を同じ評価セル・同じ fold で評価した。評価セルは、8.6.1節と同じ手順（`build_common_evaluation_set.py`）で、衛星データのみのデータセットと JRC 月次・据え置き版のデータセットから作った。JRC の6つの版は欠測の位置が同じなので、どの版から作っても同じ評価セルになる。GLC 版も同じ評価セルで実行し直したので、8.6節の GLC 版の数値とは評価セルが異なる
- **比較**: 差の向きは **JRC 版 − GLC 版** とした。Spatial CV の fold ごとの対応のある差と補正 t 区間は、8.6.3節と同じ方法で求めた（J = 5・自由度4・補正係数 0.45）。変数の寄与の比較には、4つの指標を使った（SHAP 平均絶対値・Permutation Importance・RF Importance（不純度）・線形回帰の標準化係数）。それぞれ、上位5変数の一致と、全変数の順位の Spearman 相関を見た
- **水域率の係数の元の単位**: 水域率が 0.1 増えたときの LST の変化（°C）で示した。標準化係数 × 学習データの LST の標準偏差 ÷ 学習データの水域率の標準偏差 × 0.1 で求めた（標準偏差は母標準偏差。学習データはランダム分割を同じシードで再現した）
- **数値の正本**

#### 8.7.5 読み方と限界

- **水域率の元データを JRC の3候補に替えても、性能・上位の変数の顔ぶれ・水域の係数の符号は変わらなかった。** 比べた範囲（3候補・30m・全域・シード42）では、衛星＋公開GISデータのシナリオの主結果は、水域データの選択（GLC の水域の不確かさ）に左右されない。90m・300m（RQ2）と都心部では確かめていない。主結果は方針どおり GLC 版（8.1〜8.6節）のままとする
- **水域の係数の大きさは、元データによって動く。** 水域率 +0.1 あたりの LST の変化は GLC 版の 0.87〜1.26 倍の範囲で動くため、1つの値ではなく −0.13〜−0.19°C の幅として扱う。据え置き版では湿地の係数と合わせて読む
- **単発（シード42）の比較だけである。** 区間が表すのは分割の違いによる変動だけで、標本の違いは含まない（8.6.3節）。性能の差は2.1節の標本変動（独立な2標本で 0.01程度）より小さいため、20シードの反復は行っていない
- **共通セルから外れた 279,295セル（やや暑く、水域が多い）を含まない。** JRC 月次の欠測のためである。外れたセルを含めた場合の結果は確かめていない
- **正規化版は、GLC にも JRC にもない構成を含む**（8.7.2節）。正規化版は、据え置き版の二重計上の影響を確かめるための副の版として読む
- **人口の補完の判定は GLC のままである。** 判定を JRC に合わせると、JRC だけが新たに補完するセルが最大 14,568 ある。逆に GLC だけが補完するセルも 1,111〜3,489 あるため、補完されるセルの総数の増加は最大 13,457（56,457 → 69,914）である（8.7.2節）。その影響は確かめていない
- JRC 月次は2021年9月のデータであり、観測日（2022年9月）とは年がずれる。JRC の収録が2021年までのためである
- 感度分析は 30m・全域だけで行った。90m・300m（RQ2）と都心部（測量GIS範囲）では行っていない
