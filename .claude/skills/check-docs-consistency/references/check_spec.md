# チェック仕様詳細

各チェック項目の対象・判定基準・例外を定義する。

---

## 1. docs/README.md カタログとの差分

- `docs/README.md` の「全ドキュメントカタログ」テーブルからファイルパス一覧を抽出する
- カタログに列挙された全パスと `docs/` 配下の実ファイルを比較する（拡張子で除外しない）
- 検出する差分:
  - 実ファイルが存在するがカタログに未掲載
  - カタログに記載があるが実ファイルが存在しない
  - ディレクトリ構造図（```構造```ブロック）との矛盾

## 2. リンク切れチェック

- `docs/` 配下の全 `.md` ファイルから相対パスリンクを検査する
- 外部URL（`http://`, `https://`）は対象外
- リンク先がリンク元からの相対パスで実在するか確認する（`#見出し` アンカーはパス部分のみ確認）
- `.github/` や `src/` への相対リンクも対象

## 3. メタ情報の有無チェック

ファイル冒頭の見出し（`# タイトル`）から5行以内に「最終更新」の記載があるかを確認する。
ファイル末尾や本文中の日付記載は「冒頭メタ情報あり」と判定しない。

### チェック対象外

- `docs/README.md`（カタログ文書自体）
- `docs/04_archive/02_structured_summaries/S*.md`（独自メタ形式で管理）
- `docs/04_archive/templates/structured_summary_template.md`（上記のテンプレート元）

## 4. 用語の表記揺れチェック

CLAUDE.md の最小用語集に基づき、以下を検索する:

| 対象 | 規約表記 | 揺れの例 |
|---|---|---|
| LST単位 | °C | ℃、度C、ケルビン、K |
| シナリオ名 | Satellite Only / Limited / Full | 大文字小文字、日本語訳との混在 |
| 座標系 | WGS84、EPSG:4326、VN-2000 | 表記揺れ・誤記 |
| RQ表記 | RQ1 / RQ2 / RQ3 | "RQ 1" 等の半角スペース混入 |

文脈上意図的な表記（引用文中、他研究の用語）は除外候補として注記する。

## 5. 内容レベルの整合性チェック

文書間で同一対象が異なる値で記載されていないかを確認する。

- **EPSG/CRS コード**: `EPSG:\d+` を検索し、各コードに付随するゾーン名・用途説明を文書間で比較する（必須）
- **データセット名・ファイル名の不一致**: 同じデータソースの異なる表記（ベストエフォート）
- **数値・選定結果の不一致**: 選定結果の伝播漏れ（ベストエフォート）

検出した不一致は「どちらが正しいか」を断定せず、両方の記載箇所と内容を提示する。
